# Lekcja 5.2 — Argumenty domyślne i nazwane

## Cel
Po lekcji uczeń:
- Definiuje funkcję z argumentami domyślnymi: `def f(x, y=10):`
- Wywołuje funkcję z argumentami nazwanymi: `f(x=5, y=20)`
- Wie, że argumenty pozycyjne idą **przed** nazwanymi
- Rozumie pułapkę mutowalnych argumentów domyślnych

## Krok 1 — Zakotwiczenie (3 min)
**Pytanie wejściowe:**
> "Zamawiasz pizzę. Czy zawsze musisz mówić każdy szczegół (rozmiar, ciasto, sos, dodatki)? Co gdy nie powiesz nic?"

**Co chcesz usłyszeć:** restauracja ma **ustawienia domyślne** (zwykle "średnia, klasyczne ciasto, sos pomidorowy"). Mówisz tylko to, co chcesz zmienić.

## Krok 2 — Mostek (5 min)
**Mostek:** "W funkcjach też możemy mieć **wartości domyślne** dla argumentów. Wywołujący podaje tylko to, co chce zmienić."

**Minimalny przykład:**
```python
def przywitaj(imie, powitanie="Cześć"):
    print(f"{powitanie}, {imie}!")

przywitaj("Anna")              # Cześć, Anna!
przywitaj("Borys", "Witaj")    # Witaj, Borys!
```

**Pytania:**
- "Co się stało gdy nie podałem `powitanie`?"
- "Czy mogę zmienić sam `powitanie` zostawiając imię domyślne?" → spróbuj: musimy użyć **argumentów nazwanych**.

## Krok 3 — Eksperyment (15 min)
1. **Argumenty domyślne:**
```python
def kawa(rozmiar="średnia", cukier=1):
    print(f"Kawa {rozmiar} z {cukier} łyżeczką cukru")

kawa()
kawa("duża")
kawa("mała", 0)
```
2. **Argumenty nazwane (keyword args):**
```python
kawa(cukier=3)             # kawa średnia z 3 łyżeczkami
kawa(rozmiar="duża", cukier=2)
```
3. **Mieszanie pozycyjnych i nazwanych:**
```python
kawa("duża", cukier=3)     # OK
kawa(rozmiar="duża", 3)    # BŁĄD! pozycyjny po nazwanym
```
4. **Argumenty bez wartości domyślnej muszą być przed tymi z domyślną:**
```python
def f(a, b=10): pass        # OK
def f(a=10, b): pass        # SyntaxError
```

**Po każdym pytaj:** "Co Python zrobił? Spodziewałeś się?"

## Krok 4 — Pogłębienie (15 min)

**Po co argumenty nazwane?**
- **Czytelność:** `okno(width=800, height=600, fullscreen=False)` jest znacznie czytelniejsze niż `okno(800, 600, False, True, False, 30)`.
- **Bezpieczeństwo:** nie pomylisz kolejności.

**Pułapka mutowalnych argumentów domyślnych — KLASYK Pythona:**
```python
def dodaj_do_listy(element, lista=[]):
    lista.append(element)
    return lista

print(dodaj_do_listy(1))  # [1]
print(dodaj_do_listy(2))  # [1, 2] — CO?!?!
print(dodaj_do_listy(3))  # [1, 2, 3] — WTF?!
```
Wytłumacz: domyślna lista jest **tworzona raz** przy definicji funkcji, nie przy każdym wywołaniu. To **najczęstszy bug** Pythona.

**Idiomatyczne rozwiązanie:**
```python
def dodaj_do_listy(element, lista=None):
    if lista is None:
        lista = []
    lista.append(element)
    return lista
```
Zasada: **nigdy nie używaj listy/słownika jako domyślnej wartości**. Używaj `None` i sprawdzaj.

**Funkcje z wieloma argumentami nazwanymi — przykład z prawdziwego API:**
```python
def stworz_uzytkownika(imie, email, wiek=None, miasto=None, aktywny=True):
    return {
        "imie": imie,
        "email": email,
        "wiek": wiek,
        "miasto": miasto,
        "aktywny": aktywny,
    }

u = stworz_uzytkownika(imie="Anna", email="a@a.pl", miasto="Warszawa")
```

**Typowe błędy do sprowokowania:**
- Pozycyjny po nazwanym: `f(x=5, 3)` → SyntaxError.
- Argument bez wartości po argumencie z wartością: `def f(a=1, b):` → SyntaxError.
- **Pułapka listy domyślnej** — niech uczeń sam wpadnie. To zapamięta na zawsze.

## Krok 5 — Ćwiczenie
→ Skill `cwiczenie`. Temat: "argumenty domyślne i nazwane". Sugerowane zadania:
- 🔥 Funkcja `przywitaj(imie, powitanie="Cześć")`. Wywołaj raz z, raz bez `powitanie`.
- ⭐ Funkcja `pole_prostokata(a, b=None)`. Jeśli `b` nie podane → traktuj jako kwadrat (`b = a`).
- ⚡ Funkcja `formatuj_cene(kwota, waluta="PLN", separator=" ")`. Wypisuje `f"{kwota}{separator}{waluta}"`. Wywołaj raz z domyślnymi, raz z `waluta="EUR"`, raz z `separator=""`.

## Pułapki
- **Mutowalne argumenty domyślne** (`def f(x=[])`) — to **bug magnet**. Używaj `None`.
- **Kolejność:** pozycyjne bez wartości → pozycyjne z wartością → nazwane przy wywołaniu.
- **Pozycyjny argument po nazwanym** — SyntaxError przy wywołaniu.
- **Domyślne wartości są obliczane raz** — `def f(x=time.time())` da CAŁY CZAS ten sam czas (czas definicji), nie czas wywołania.

## Aktualizacja 2026 (z `AKTUALIZACJE.md`)
- **Pozycyjne-tylko i nazwane-tylko** (3.8+):
```python
def f(a, b, /, c, d, *, e, f):  # a,b tylko pozycyjnie; e,f tylko nazwane
    ...
```
Dla początkującego — pomiń, ale wzmiankuj.
- **Type hints na argumentach:** `def f(x: int, y: int = 10) -> int:`

## Notatki tutora
- **Pułapka listy domyślnej** to **MUSI** dla każdego ucznia. Niech sprowokuje, niech będzie zaskoczony, niech naprawi.
- **Argumenty nazwane to elegancja**, nie ozdoba. Pokaż na przykładzie z 6 argumentami, jak strasznie wygląda bez nazw.
- Nie wprowadzaj `*args` i `**kwargs` — to wzmianka w lekcji 5.3 lub pominięte (zaawansowane).
