# Lekcja 4.1 — Listy: indeksowanie, slicing, metody

## Cel
Po lekcji uczeń:
- Tworzy listę, dodaje/usuwa elementy
- Indeksuje (od 0!) i robi slicing (`lista[1:4]`)
- Iteruje po liście pętlą `for`
- Zna metody: `append`, `pop`, `remove`, `sort`, `reverse`, `len`

## Krok 1 — Zakotwiczenie (3 min)
**Pytanie wejściowe:**
> "Robisz listę zakupów. Co możesz na niej zrobić — fizycznie, długopisem?"

**Co chcesz usłyszeć:** dopisać, wykreślić, zmienić kolejność, sprawdzić ile pozycji, ile zostało. To wszystko będziemy mieli w Pythonie.

## Krok 2 — Mostek (5 min)
**Mostek:** "W Pythonie kolekcję wartości w określonej kolejności nazywamy **listą**. Wartości to **elementy**. Każdy ma swoje **miejsce** — numer od 0."

**Minimalny przykład:**
```python
zakupy = ["chleb", "mleko", "ser"]
print(zakupy)
print(zakupy[0])  # pierwszy element — chleb
```

**Pytania:**
- "Co tu jest listą? Co elementem?"
- "Czemu `zakupy[0]` to chleb, a nie mleko?" → bo **liczymy od zera**. To nie błąd — to konwencja Pythona (i większości języków).

## Krok 3 — Eksperyment (20 min)
1. **Indeksowanie:**
```python
zakupy = ["chleb", "mleko", "ser", "masło"]
print(zakupy[0])    # chleb
print(zakupy[3])    # masło
print(zakupy[-1])   # masło (od końca!)
print(zakupy[-2])   # ser
```
2. **Długość:** `len(zakupy)` → 4
3. **Zmiana elementu:** `zakupy[0] = "bułka"` — element pod indeksem 0 jest teraz "bułka"
4. **Slicing (wykrawanie):**
```python
zakupy[0:2]   # ["bułka", "mleko"] — od 0 do 2 (wyłącznie)
zakupy[:2]    # to samo
zakupy[2:]    # ["ser", "masło"] — od 2 do końca
zakupy[:]     # cała lista (kopia)
```
5. **Iteracja:**
```python
for produkt in zakupy:
    print(f"Kupić: {produkt}")
```
6. **Metody:**
- `zakupy.append("jajka")` — dodaj na koniec
- `zakupy.insert(0, "sok")` — dodaj na pozycję 0
- `zakupy.pop()` — usuń i zwróć ostatni
- `zakupy.pop(0)` — usuń i zwróć pierwszy
- `zakupy.remove("ser")` — usuń pierwsze wystąpienie "ser"
- `zakupy.sort()` — posortuj alfabetycznie (modyfikuje!)
- `zakupy.reverse()` — odwróć kolejność
- `"ser" in zakupy` → True/False

**Po każdej operacji wypisz listę** i zapytaj: "Czego się spodziewałeś?"

## Krok 4 — Pogłębienie (15 min)

**Lista może mieszać typy:**
```python
mix = [1, "ala", 3.14, True]
```
Tak, ale **nie polecane** — listy zwykle są jednorodne (same teksty / same liczby).

**Dodawanie list:**
```python
a = [1, 2, 3]
b = [4, 5, 6]
print(a + b)  # [1, 2, 3, 4, 5, 6]
print(a * 3)  # [1, 2, 3, 1, 2, 3, 1, 2, 3]
```

**Suma liczb w liście:**
```python
liczby = [3, 7, 2, 8, 5]
print(sum(liczby))  # 25
print(min(liczby))  # 2
print(max(liczby))  # 8
```

**Typowe błędy do sprowokowania:**
- `zakupy[10]` (poza zakresem) → `IndexError`. Niech uczeń sam sprowokuje.
- `zakupy.remove("nic")` (czego nie ma) → `ValueError`.
- **Zaskakujące:** `lista2 = lista1` — to **referencja**, nie kopia! Zmiana w `lista2` zmienia `lista1`. Niech uczeń sprawdzi:
```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)  # [1, 2, 3, 4] — ALE SKĄD?!
```
Wytłumacz: `b = a` to "ta sama naklejka na pudełko". Żeby skopiować: `b = a.copy()` lub `b = a[:]` lub `b = list(a)`.

## Pułapki
- **Indeksowanie od 0** — nie od 1. Zapamiętaj.
- **Slicing — stop wyłączone**, jak w `range`. `lista[1:3]` to indeksy 1 i 2 (NIE 3).
- **`sort()` modyfikuje listę**, `sorted(lista)` zwraca nową. Pamiętaj różnicę.
- **`lista2 = lista1` to referencja**, nie kopia. Najczęstszy "zaskakujący błąd" początkujących.
- **Lista jest mutowalna** (można zmieniać). Krotka (lekcja 4.2) nie.

## Aktualizacja 2026 (z `AKTUALIZACJE.md`)
- **List comprehensions** — wspomnij jako "kiedyś dojdziemy" (moduł 10):
```python
kwadraty = [x**2 for x in range(10)]
```
Wytłumacz: to skrócona pętla. Nie wprowadzaj jeszcze — niech uczeń pisze klasycznie.
- **`list[int]` jako type hint** (3.9+) — gdyby uczeń pytał o typy: `def f(lista: list[int]):`. Nie wymuszaj.

## Notatki tutora
- **Slicing i indeksowanie od 0** to dwa najbardziej "zaskakujące" rzeczy. Nie spiesz się.
- Pokaż **przykład z prawdziwego życia** — "lista zakupów", "uczniowie w klasie", "ulubione filmy". Nie `[1, 2, 3]`.
- **Nie wprowadzaj `del`** — `pop` i `remove` wystarczą.
- Jeśli uczeń pyta o **dwuwymiarowe listy** (lista list) — pokaż w pogłębieniu, ale głębiej w lekcji 4.4 (zagnieżdżenia).
