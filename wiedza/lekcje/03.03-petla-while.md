# Lekcja 3.3 — Pętla `while`, `break`, `continue`

## Cel
Po lekcji uczeń:
- Pisze `while` z warunkiem zakończenia
- Rozumie, kiedy `while` lepsze niż `for` (gdy nie wie ile razy)
- Używa `break` (wyjdź) i `continue` (pomiń iterację)
- Unika nieskończonych pętli; jeśli wpadnie — używa `Ctrl+C`

## Krok 1 — Zakotwiczenie (5 min)
**Pytanie wejściowe:**
> "Czytasz książkę. Czytasz JAK DŁUGO? Sformułuj regułę."

**Co chcesz usłyszeć:** "Dopóki nie skończę rozdziału" / "Dopóki mi się chce" / "Dopóki nie zaśnę". Czyli: **dopóki warunek X** — bez znajomości z góry ile to potrwa.

## Krok 2 — Mostek (5 min)
**Mostek:** "To **dokładnie** druga pętla: `while` — 'tak długo, jak warunek jest prawdziwy'. Różnica względem `for`: tam wiesz ile razy (lub po jakim zbiorze). Tu wiesz tylko warunek wyjścia."

**Minimalny przykład:**
```python
i = 0
while i < 5:
    print(i)
    i += 1
```

**Pytania:**
- "Kiedy pętla się zakończy?"
- "Co się stanie, jeśli usunę `i += 1`?" → Niech uczeń sam wywoła nieskończoną pętlę i przerwij `Ctrl+C`. To **bardzo cenne doświadczenie**.

Wprowadź: **warunek pętli**, **modyfikacja zmiennej w ciele pętli** (krytyczne dla `while`), **nieskończona pętla** + **Ctrl+C**.

## Krok 3 — Eksperyment (15 min)
1. Pętla "policz w górę do 5":
```python
i = 1
while i <= 5:
    print(i)
    i += 1
```
2. Pętla "policz w dół od 10":
```python
i = 10
while i > 0:
    print(i)
    i -= 1
print("Start!")
```
3. **Pętla z input:**
```python
haslo = ""
while haslo != "ananas":
    haslo = input("Podaj hasło: ")
print("Witaj!")
```
4. **Pętla z `True` + `break`** (idiom "do-while" w Pythonie):
```python
while True:
    odp = input("'tak' żeby kontynuować, 'nie' żeby wyjść: ")
    if odp == "nie":
        break
    print("kontynuuję...")
```

**Po każdym pytaj:** "Co Python zrobił? Co go zatrzymało?"

## Krok 4 — Pogłębienie (15 min)

**`break` — wyjdź z pętli natychmiast:**
```python
for i in range(100):
    if i == 5:
        break
    print(i)  # wypisze 0,1,2,3,4
```

**`continue` — pomiń resztę tej iteracji:**
```python
for i in range(10):
    if i % 2 == 0:
        continue  # parzyste pomiń
    print(i)  # wypisze 1,3,5,7,9
```

**`for` vs `while` — kiedy co?**

| Sytuacja                                          | Wybór    |
| ------------------------------------------------- | -------- |
| Wiem ile razy ma się wykonać (10 razy)            | `for`    |
| Iteruję po liście / stringu / range               | `for`    |
| Czekam aż użytkownik wpisze coś konkretnego       | `while`  |
| Czytam plik linijka po linijce do końca          | `for` (moduł 6) |
| Pętla "uruchom dopóki gracz nie powie stop"       | `while`  |

**Typowe błędy do sprowokowania:**
- Brak modyfikacji w `while` → nieskończona pętla. Sprowokuj, przerwij `Ctrl+C`.
- `while x > 0` ale `x` nigdy nie maleje → nieskończona.
- `break` poza pętlą → SyntaxError.

## Krok 5 — Ćwiczenie
→ Skill `cwiczenie`. Temat: "kontrola przepływu". Sugerowane zadania:
- 🔥 "Zgadnij liczbę 7" — w pętli pytaj o liczbę, dopóki nie poda 7
- ⭐ "Suma do 100" — pytaj o liczby, sumuj, gdy suma > 100, wypisz wynik i wyjdź
- ⚡ "Gra w zgadywankę" — Python ma w głowie liczbę 42 (na sztywno). Gracz zgaduje. Po każdej próbie podpowiedz "za mało" / "za dużo" / "trafiony!". Licz próby. Po trafieniu wypisz ile prób zajęło.

## Pułapki
- **Nieskończona pętla** — najczęściej brak modyfikacji warunku. Zawsze pytaj: "co w ciele pętli zmienia warunek?"
- **Pętla wykonuje się 0 razy** — gdy warunek **od początku** False (np. `i = 10; while i < 5: ...`). To poprawne, ale pułapka.
- **Pomylenie `break` z `continue`** — `break` wychodzi, `continue` skacze do następnej iteracji.
- **Modyfikacja warunku w nieoczywistym miejscu** — np. `while not znalezione:` wymaga gdzieś w środku `znalezione = True`. Łatwo zapomnieć.

## Aktualizacja 2026 (z `AKTUALIZACJE.md`)
- **Walrus operator `:=`** (3.8+) — skraca pętle z `input()`:
```python
# klasyka:
linia = input()
while linia != "stop":
    print(linia)
    linia = input()

# z walrusem:
while (linia := input()) != "stop":
    print(linia)
```
Pokaż jako "ciekawszy sposób", ale klasyka to baza.

## Notatki tutora
- **Nieskończona pętla + Ctrl+C** to **kluczowa lekcja** — niech uczeń przeżyje to świadomie. Bez tego będzie się bał `while`.
- Jeśli uczeń woli `while True: break` zamiast warunku — to OK, częsty idiom. Pokaż jednak elegancję czystego warunku, gdy się da.
- **Nie wprowadzaj `else` po pętli** (`for ... else: ...`) — to ezoteryczna konstrukcja, nie dla początkujących.
