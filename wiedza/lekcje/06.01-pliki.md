# Lekcja 6.1 — Czytanie i zapisywanie plików tekstowych

## Cel
Po lekcji uczeń:
- Czyta plik tekstowy linijka po linijce
- Zapisuje do pliku (`w`) i dopisuje (`a`)
- Używa `with open(...)` jako standardu
- Zawsze podaje `encoding="utf-8"` przy plikach tekstowych
- Wie o `pathlib.Path` jako współczesnej alternatywie

## Krok 1 — Zakotwiczenie (5 min)
**Pytanie wejściowe:**
> "Twój program kończy działanie. Wszystkie dane, które miał w zmiennych — co się z nimi dzieje?"

**Co chcesz usłyszeć:** giną. RAM jest ulotny. Żeby coś przetrwało między uruchomieniami, trzeba zapisać na dysk — do pliku.

## Krok 2 — Mostek (5 min)
**Mostek:** "Plik to **trwały magazyn danych**. Program może go zapisać i potem odczytać. To jak notes na biurku — zawartość zostaje, gdy wyjdziesz z pokoju."

**Minimalny przykład — zapis:**
```python
with open("notatki.txt", "w", encoding="utf-8") as f:
    f.write("Pierwsza linia\n")
    f.write("Druga linia\n")
```

**Minimalny przykład — odczyt:**
```python
with open("notatki.txt", "r", encoding="utf-8") as f:
    tresc = f.read()
print(tresc)
```

**Pytania:**
- "Co znaczy `'w'` i `'r'`?" (write, read)
- "Co robi `with`?" (zamyka plik automatycznie po wyjściu z bloku — kluczowa rzecz)
- "Czemu `\n`?" (znak nowej linii)

## Krok 3 — Eksperyment (15-20 min)
1. **Zapis pliku:**
```python
with open("test.txt", "w", encoding="utf-8") as f:
    f.write("Cześć, świecie!\n")
    f.write("Polskie znaki: ąęłźć\n")
```
Otwórz plik w VS Code — sprawdź, czy polskie znaki wyglądają OK.

2. **Odczyt całego pliku:**
```python
with open("test.txt", "r", encoding="utf-8") as f:
    print(f.read())
```

3. **Odczyt linia po linii (idiom!):**
```python
with open("test.txt", "r", encoding="utf-8") as f:
    for linia in f:
        print(linia.strip())  # strip() usuwa \n na końcu
```

4. **Tryby otwarcia:**
- `"r"` — read (czytaj). Plik MUSI istnieć.
- `"w"` — write (pisz). **Nadpisuje!** Jeśli istniał — kasuje zawartość.
- `"a"` — append (dopisz). Dodaje na końcu.
- `"x"` — exclusive create. Błąd jeśli istnieje.

5. **Dopisywanie:**
```python
with open("test.txt", "a", encoding="utf-8") as f:
    f.write("nowa linia na końcu\n")
```

**Po każdym pytaj:** "Sprawdź plik w edytorze — co się stało?"

## Krok 4 — Pogłębienie (15 min)

**Praktyczny przykład — licznik wystąpień słów w pliku:**
```python
licznik = {}
with open("test.txt", "r", encoding="utf-8") as f:
    for linia in f:
        for slowo in linia.split():
            licznik[slowo] = licznik.get(slowo, 0) + 1
print(licznik)
```

**Czytanie do listy linii:**
```python
with open("test.txt", "r", encoding="utf-8") as f:
    linie = f.readlines()  # zwraca listę
print(linie)  # ["linia 1\n", "linia 2\n", ...]
```

**Zapis listy linii:**
```python
linie = ["pierwsza", "druga", "trzecia"]
with open("out.txt", "w", encoding="utf-8") as f:
    f.write("\n".join(linie) + "\n")
```
Wytłumacz `"\n".join(...)`: skleja listę w jeden string z separatorem.

**`pathlib` — współczesna alternatywa:**
```python
from pathlib import Path

# odczyt:
tresc = Path("test.txt").read_text(encoding="utf-8")

# zapis:
Path("nowy.txt").write_text("treść\n", encoding="utf-8")

# sprawdzenie istnienia:
if Path("test.txt").exists():
    print("istnieje")
```
Pokaż obie metody — `with open` jest klasyką, `Path` współczesnym idiomem (zwłaszcza dla krótkich operacji).

**Typowe błędy do sprowokowania:**
- Czytanie nieistniejącego pliku → `FileNotFoundError`.
- Brak `encoding="utf-8"` na Windowsie → krzaki na polskich znakach.
- Zapomniany `\n` przy `write` → wszystko w jednej linii.
- Bez `with` — trzeba ręcznie `f.close()`, a jak zapomnisz, plik może nie zapisać się do końca.

## Krok 5 — Ćwiczenie
→ Skill `cwiczenie`. Temat: "praca z plikami". Sugerowane zadania:
- 🔥 Zapisz do pliku `wizytowka.txt` 5 linii o sobie. Potem odczytaj i wypisz.
- ⭐ "Mini-pamiętnik" — pętla pytająca o wpis (lub "exit"). Wpisy dopisuj do `pamietnik.txt` (z datą — użyj `from datetime import date; date.today()`).
- ⚡ Wczytaj plik z imionami (jedno w linijce), policz unikalne (użyj `set`), wypisz w porządku alfabetycznym (`sorted`).

## Pułapki
- **Bez `encoding="utf-8"`** — Windows domyślnie używa `cp1250`. Krzaki gwarantowane przy polskich znakach. **Zawsze pisz `encoding="utf-8"`.**
- **Tryb `"w"` kasuje zawartość!** Jeśli chciałeś dopisać — to `"a"`.
- **`f.write` nie dodaje `\n` automatycznie.** Musisz sam.
- **Bez `with`** — możliwe że plik nie zapisze się przed końcem programu. **Zawsze `with`.**
- **Ścieżki względne** — `open("plik.txt")` szuka w **bieżącym katalogu** (tym z którego uruchomiłeś `python3`). Sprawdź `pwd` jeśli "nie widzi".

## Aktualizacja 2026 (z `AKTUALIZACJE.md`)
- **`pathlib` to STANDARD w 2026** dla manipulacji ścieżkami. `os.path.join`, `os.path.exists` itd. są nadal w stdlib, ale `pathlib` jest **czytelniejsze** i obiektowe. Polecaj.
- **`encoding="utf-8"` ZAWSZE** — to nie opcja, to konieczność. W Python 3.10+ jest ostrzeżenie w trybie deweloperskim, jeśli pominiesz.
- **`open(path, "w").write(...)` w jednej linii** — działa, ale bez `with` plik się nie zamknie poprawnie w niektórych implementacjach Pythona (np. PyPy). Trzymaj się `with`.

## Notatki tutora
- **Polskie znaki + encoding** to praktyczna rzecz. Niech uczeń sprowokuje błąd encoding (np. otwarcie pliku w innym encodingu) — to lekcja na zawsze.
- **`pathlib` vs `open`** — pokaż oba. Niech uczeń wybierze, co bardziej mu odpowiada. W 2026 `pathlib` ma przewagę dla prostych operacji, `with open` zostaje dla streamowania dużych plików.
- **Nie wchodź w pliki binarne (`"rb"`, `"wb"`)** ani w `csv`/`json` — to moduł 9.
- Pokaż na koniec **gdzie plik się zapisał** (`Path.cwd()` lub `pwd`) — uczeń może go "nie znaleźć".
