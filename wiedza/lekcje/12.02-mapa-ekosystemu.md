# Lekcja 12.2 — Mapa ekosystemu Pythona

## Cel
Po lekcji uczeń:
- Wie, że Python ma **kilka dużych "krain"**: web, data, ML, automation, scripting
- Zna **kluczowe biblioteki** każdej (Django, pandas, PyTorch, ...)
- Wie, co wybrać na podstawie celu
- Ma **mapę do dalszej nauki** (a nie 10 random tutorialów)

## Krok 1 — Zakotwiczenie (3 min)
**Pytanie wejściowe:**
> "Skończyłeś podstawy. Mówisz znajomemu: 'idę dalej z Pythonem'. Jakie 3 pytania zada Ci znajomy, żeby Cię ukierunkować?"

**Co chcesz usłyszeć:** Co chcesz robić? Praca/hobby? Lubisz dane/strony/automatyzację/gry/AI? **Kierunek** określa **bibliotekę**, której się uczysz.

**Mostek:** "Python to **jedno z najwszechstronniejszych narzędzi** programisty. Możesz robić praktycznie wszystko — ale **każda dziedzina** ma swoje biblioteki. Mapowanie tych dziedzin to dzisiejsza lekcja."

## Krok 3 — Eksperyment — mapa krain (20-25 min)

### 🌐 Web — backend

| Biblioteka     | Do czego                                        | Trudność |
| -------------- | ----------------------------------------------- | -------- |
| **Flask**      | Małe API/aplikacje, szybki start, mikro-framework | ⭐⭐       |
| **FastAPI**    | API, async, automatyczna dokumentacja           | ⭐⭐⭐      |
| **Django**     | Pełne aplikacje webowe, batteries-included      | ⭐⭐⭐⭐     |
| **Streamlit**  | Demo / panele bez frontendu                     | ⭐        |

Typowy stack 2026 dla API: **FastAPI + SQLModel + uvicorn**.

Mini-przykład Flask:
```python
from flask import Flask
app = Flask(__name__)

@app.route("/")
def hello():
    return "Cześć!"
```

## Krok 4 — Pogłębienie — dobór ścieżki (10 min)

### Jaką ścieżkę wybrać?

**Lubisz dane, statystyki, analizę?** → Data Science
- Nauka: pandas → matplotlib → scikit-learn → PyTorch (jeśli chcesz głębiej)
- Projekt: analiza datasetu z Kaggle

**Lubisz strony/aplikacje?** → Web Backend
- Nauka: Flask (szybki) lub FastAPI → SQL (pójdziesz w SQLite najpierw)
- Projekt: API CRUD, np. blog lub lista zadań

**Lubisz automatyzację, narzędzia?** → Scripting/DevOps
- Nauka: pathlib + subprocess → cli (`click`/`typer`) → docker
- Projekt: narzędzie CLI ułatwiające Twoje codzienne zadanie

**Interesuje Cię AI/LLM?** → Modern AI
- Nauka: `anthropic` SDK / `openai` SDK → LangChain → embedding/RAG
- Projekt: prosty chatbot na bazie Twoich notatek

**Gry?** → pygame
- Nauka: pygame → arcade → projekt gry 2D

### Reguły rozsądnej nauki dalszego

1. **Wybierz JEDNĄ krainę** na 6 miesięcy. Nie skacz między nimi.
2. **Projekt > tutoriale** — buduj coś, ucząc się
3. **Open source** — czytaj kod doświadczonych
4. **Społeczność** — Discord, Stack Overflow, GitHub
5. **Konsekwencja** — 30 min codziennie > 5 godzin raz w tygodniu

## Pułapki
- **Skakanie między krainami** — uczysz się trochę web, trochę ML, trochę gier → brak postępu w niczym.
- **"Najpierw nauczę się wszystkiego"** — niemożliwe. Wybierz **jedno**.
- **Trzymanie się starych bibliotek** — `urllib`, `setup.py`, `os.path`. W 2026 są nowsze.
- **Naśladowanie tutoriali bez własnych projektów** — najgorsze. Stwórz, zbuduj, doświadcz.

## Aktualizacja 2026 (z `AKTUALIZACJE.md`)
- **Polars > pandas** dla nowych projektów (szybsze, czystsze API).
- **FastAPI > Flask** dla nowych API (async, type hints, automatyczne docs).
- **uv > pip + venv** dla zarządzania pakietami.
- **ruff > pylint + flake8 + black** — wszystko w jednym.
- **PyTorch dominuje w ML**, TensorFlow ma się słabiej.
- **AI/LLM** — najszybciej rosnąca dziedzina. LangChain, embeddings, RAG.
