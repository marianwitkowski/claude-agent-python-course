# Lekcja 2.2 — Operatory i wyrażenia

## Cel
Po lekcji uczeń:
- Używa operatorów arytmetycznych: `+`, `-`, `*`, `/`, `//`, `%`, `**`
- Rozumie różnicę między `/` (zwraca float) a `//` (zwraca int — dzielenie całkowite)
- Stosuje nawiasy do kontroli kolejności działań
- Używa skróconych operatorów (`+=`, `-=`, `*=`)

## Krok 1 — Zakotwiczenie (3 min)
**Pytanie wejściowe:**
> "Masz w głowie wyrażenie: `2 + 3 × 4`. Ile to jest?"

**Co chcesz usłyszeć:** 14, nie 20. Dlaczego? Bo mnożenie pierwsze (kolejność działań ze szkoły).
**Czego NIE rób:** nie tłumacz jeszcze "priorytetów operatorów".

## Krok 2 — Mostek (3 min)
**Mostek:** "Python liczy dokładnie tak, jak nauczyłeś się w szkole. Mnożenie/dzielenie przed dodawaniem/odejmowaniem. Nawiasy nadrzędne. Tylko symbol mnożenia inny — gwiazdka `*`, nie `×`."

**Minimalny przykład:**
```python
print(2 + 3 * 4)       # 14
print((2 + 3) * 4)     # 20
```

## Krok 3 — Eksperyment (15 min)
W REPL (idealne miejsce na eksperymenty z liczbami):

1. **Dodawanie/odejmowanie:** `7 + 3`, `7 - 3`
2. **Mnożenie:** `4 * 5`. **Potęgowanie:** `2 ** 10` (1024).
3. **Dwa rodzaje dzielenia:**
   - `7 / 2` → 3.5 (zwykłe, zwraca **float**)
   - `7 // 2` → 3 (całkowite, **int**)
   - Niech uczeń sam sprawdzi `type(7/2)` i `type(7//2)`
4. **Modulo (reszta z dzielenia):** `7 % 2` → 1, `10 % 3` → 1, `10 % 5` → 0
5. **Operator dla stringów:**
   - `"a" + "b"` → "ab" (konkatenacja)
   - `"ab" * 3` → "ababab" (powtórzenie)
   - `"a" - "b"` → **błąd!** TypeError

**Po każdym pytaj:** "Spodziewałeś się takiego wyniku?"

## Krok 4 — Pogłębienie (15 min)

**Skrócone operatory** — bardzo popularne:
```python
licznik = 10
licznik += 1   # to samo co: licznik = licznik + 1
licznik -= 3   # licznik = licznik - 3
licznik *= 2   # licznik = licznik * 2
print(licznik) # ?
```
Niech uczeń policzy w głowie zanim uruchomi. Potem sprawdzi.

**Modulo w praktyce:**
- "Czy liczba jest parzysta?" → `liczba % 2 == 0`
- "Czy minęła pełna godzina?" → `minuty % 60 == 0`
- Konwersja sekund na minuty i sekundy: `296 // 60` = 4, `296 % 60` = 56 → "4 min 56 s"

**Priorytety operatorów (skrócona ściąga):**
1. `**` (potęga) — najwyższy
2. `*`, `/`, `//`, `%`
3. `+`, `-` — najniższy
4. Nawiasy `(...)` — nadrzędne

**Typowe błędy do sprowokowania:**
- `2 ** 1000` — Python liczy gigantyczne liczby bez problemu (w innych językach byłby overflow). Pokaż.
- `0.1 + 0.2` → 0.30000000000000004 (!!). Float ma ograniczoną precyzję. Wytłumacz: nie "Python się myli", tylko reprezentacja liczb dziesiętnych w binarnym (potem moduł 9 jeśli `decimal`).
- `5 / 0` → `ZeroDivisionError`. Pokaż błąd.

## Krok 5 — Ćwiczenie
→ Skill `cwiczenie`. Temat: "obliczenia". Sugerowane zadania:
- 🔥 Mam 7 jabłek, kolega 5. Ile razem? Ile średnio na osobę?
- ⭐ Konwersja: 137 minut → ile to godzin i minut? Użyj `//` i `%`.
- ⚡ Pole prostokąta o bokach 5.5 i 3.2. Obwód. Potęga: `bok ** 2` dla kwadratu.

## Pułapki
- **Dzielenie liczb całkowitych** — w Pythonie 3 `7 / 2 = 3.5` (float), w Pythonie 2 byłoby `3` (int). Pamiętaj.
- **Float ma ograniczoną precyzję** — nie używaj do pieniędzy (`Decimal` w stdlib na to).
- **`**` to potęga**, nie XOR (jak w niektórych językach).
- **`%` w Pythonie to modulo**, NIE "procent" (jak w niektórych innych miejscach).
- **Stringów nie odejmiesz, nie podzielisz** — tylko `+` i `*` (przez liczbę).

## Aktualizacja 2026 (z `AKTUALIZACJE.md`)
- Wzmianka: w 3.12+ liczby mogą być pisane z podkreślnikami dla czytelności: `1_000_000`. Pokaż: `print(1_000_000)`.
- Operator walrus `:=` — wspomnimy w module 3 (pętle). Nie wprowadzaj jeszcze.

## Notatki tutora
- **Niech uczeń liczy w głowie** zanim uruchomi — to buduje intuicję. Najpierw zgaduje wynik, potem sprawdza.
- Jeśli uczeń pyta o moduło "po co to" — pokaż przykład parzystych/nieparzystych. Konkret rozumieją.
- **Nie wprowadzaj `divmod`** ani innych "egzotycznych" — moduł 9.
