# Lekcja 10.3 — List / dict / set comprehensions

## Cel
Po lekcji uczeń:
- Pisze `[x*2 for x in lista]` zamiast `for + append`
- Stosuje filtr w comprehension: `[x for x in lista if x > 0]`
- Pisze dict comprehension: `{k: v for k, v in pary}`
- Wie kiedy comprehension czytelne, a kiedy zwykła pętla lepsza

## Krok 1 — Zakotwiczenie (3 min)
**Pytanie wejściowe:**
> "Mówisz: 'wszyscy moi koledzy mający > 25 lat'. Czy to potrzebuje 5 zdań i przerzucania kartek, czy jedno zdanie ze szczegółami?"

**Co chcesz usłyszeć:** jedno zdanie. **Deklaratywnie** opisujesz co chcesz, nie krok po kroku jak. Tak działają comprehensions — opis wyniku zamiast instrukcji.

## Krok 2 — Mostek (5 min)
**Mostek:** "**Comprehension** to skrócony zapis tworzenia kolekcji. Zamiast `for + append`, piszesz w jednej linii: 'lista [wyrażenie] dla każdego [zmienna] w [źródle]'. Wynik: krótszy, czytelniejszy, szybszy kod."

**Minimalny przykład:**
```python
# klasyka:
kwadraty = []
for x in range(10):
    kwadraty.append(x ** 2)

# comprehension:
kwadraty = [x ** 2 for x in range(10)]
print(kwadraty)   # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
```

**Pytanie:** "Czy comprehension robi DOKŁADNIE to samo? Czy poznajesz w niej `for` i `append`?"

## Krok 3 — Eksperyment (15-20 min)

**1. Transformacja:**
```python
liczby = [1, 2, 3, 4, 5]
print([x * 2 for x in liczby])           # [2, 4, 6, 8, 10]
print([x ** 2 for x in liczby])           # [1, 4, 9, 16, 25]

imiona = ["anna", "borys", "cecylia"]
print([s.upper() for s in imiona])         # ['ANNA', 'BORYS', 'CECYLIA']
print([len(s) for s in imiona])            # [4, 5, 7]
```

**2. Filtrowanie (warunek `if`):**
```python
print([x for x in liczby if x % 2 == 0])  # [2, 4]
print([x for x in range(20) if x % 3 == 0])  # [0, 3, 6, 9, 12, 15, 18]
```

**3. Transformacja + filtrowanie:**
```python
print([x ** 2 for x in liczby if x % 2 == 0])  # [4, 16]
# czytaj: "kwadrat każdego x, dla x w liczby, jeśli x parzyste"
```

**4. Warunek w wyrażeniu (`if/else` ZAMIAST filtra):**
```python
# Tu IF/ELSE jest częścią wyrażenia, NIE filtrem:
print([x if x > 0 else 0 for x in [-1, 2, -3, 4]])
# [0, 2, 0, 4]
# czytaj: "x jeśli dodatnie, w przeciwnym razie 0, dla każdego x"
```
Pokaż uczniowi różnicę: warunek **na końcu** to filtr, warunek **przed** `for` to ternary w wyrażeniu.

**5. Dict comprehension:**
```python
print({x: x ** 2 for x in range(5)})
# {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

# Z dwóch list:
imiona = ["Anna", "Borys", "Cecylia"]
wieki = [30, 25, 40]
print({imie: wiek for imie, wiek in zip(imiona, wieki)})
# {'Anna': 30, 'Borys': 25, 'Cecylia': 40}

# Odwrócenie słownika:
d = {"a": 1, "b": 2, "c": 3}
print({v: k for k, v in d.items()})
# {1: 'a', 2: 'b', 3: 'c'}
```

**6. Set comprehension:**
```python
slowa = ["ala", "ma", "ala", "kota", "kot", "ma"]
unikalne_dlugosci = {len(s) for s in slowa}
print(unikalne_dlugosci)   # {2, 3, 4}
```

**Po każdym pytaj:** "Co Python zrobił? Jak byś to napisał pętlą?"

## Krok 4 — Pogłębienie (15 min)

**Generator expression — bez listy w pamięci:**
```python
gen = (x ** 2 for x in range(1000000))
# Nie tworzy listy! Iterator — wartości na żądanie.
print(sum(gen))   # 333_332_833_333_500_000
```
Dla `sum`, `max`, `min`, `any`, `all` możesz pominąć `[...]` i pisać `sum(x ** 2 for x in dane)` — Python akceptuje. To **memory-efficient**.

**Zagnieżdżone comprehensions** (uwaga, łatwo o nieczytelność):
```python
# Wszystkie pary z dwóch list:
pary = [(x, y) for x in [1, 2, 3] for y in ['a', 'b']]
print(pary)
# [(1,'a'),(1,'b'),(2,'a'),(2,'b'),(3,'a'),(3,'b')]

# Spłaszczenie listy list:
matryca = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
plaska = [x for wiersz in matryca for x in wiersz]
print(plaska)   # [1,2,3,4,5,6,7,8,9]
```
**Reguła:** jeśli zagnieżdżona comprehension jest dłuższa niż 1 linia — przepisz na pętlę.

**Kiedy comprehension, kiedy pętla:**

| Sytuacja                                  | Wybór                      |
| ----------------------------------------- | -------------------------- |
| Prosta transformacja                      | comprehension              |
| Filtr + transformacja                     | comprehension              |
| Side effects (`print`, zapis do pliku)   | pętla (comprehension to **wartość**) |
| Wiele warunków, złożona logika           | pętla                      |
| Iteracja po jednej linii kodu             | comprehension              |
| Memory matters (miliony elementów)        | generator expression       |

**Typowe błędy do sprowokowania:**
- `[print(x) for x in range(5)]` — działa, ale tworzy bezsensowną listę `[None, None, None, None, None]`. Comprehension dla **wartości**, nie efektów ubocznych.
- Zbyt zagnieżdżona comprehension → nieczytelna. Niech uczeń napisze, potem przepisze na pętlę i porówna.
- Pomylenie `if` jako filtra z `if/else` jako ternary.

## Krok 5 — Ćwiczenie
→ Skill `cwiczenie`. Temat: "comprehensions". Sugerowane zadania:
- 🔥 Lista `[1, 5, 10, 15, 20]`. Comprehension: pomnóż każdy przez 3. Comprehension z filtrem: wybierz > 10. Comprehension z transformacją i filtrem: kwadraty > 10.
- ⭐ Słownik `oceny = {"matma": 4, "polski": 5, "chemia": 3, "fizyka": 5}`. Dict comprehension: tylko przedmioty z oceną 5. Drugi: zamień klucze na duże litery.
- ⚡ Lista 10 osób (dict z `imie`, `wiek`, `miasto`). Comprehensions: lista imion >18, lista par (imie, miasto), słownik {imie: wiek}, zbiór unikalnych miast.

## Pułapki
- **Comprehension dla efektów ubocznych** (`print`, side effects) — anty-idiom. Użyj pętli.
- **Zagnieżdżone comprehensions** — łatwo o nieczytelność. >1 linia = pętla.
- **`if/else` w wyrażeniu vs `if` jako filtr** — różne pozycje. Łatwo pomylić.
- **Comprehension z `:=`** (walrus) — można, ale dla początkujących zbędna komplikacja.
- **Pomylony `{}` jako pusty set** — `{}` to dict. Set comprehension: `{x for x in ...}` lub `set()` dla pustego.

## Aktualizacja 2026 (z `AKTUALIZACJE.md`)
- **Comprehensions to dominujący idiom 2026** — używaj zamiast `map`/`filter` w 80% przypadków.
- **Generator expressions** dla dużych danych — pamięciowo wydajne. `sum(x**2 for x in dane)` nie tworzy listy.
- **`async`/`await` comprehensions** (zaawansowane, async-IO):
```python
result = [x async for x in async_iterator]
```

## Notatki tutora
- **To może być WOW dla ucznia** — pokaż przepisanie 5-liniowej pętli na 1-liniową comprehension.
- **Nie wymuszaj comprehensions wszędzie** — pętla jest OK, gdy czytelniej.
- **Generator expression** — pokaż jako "pamięciowo wydajne" — uczeń doceni przy dużych danych.
