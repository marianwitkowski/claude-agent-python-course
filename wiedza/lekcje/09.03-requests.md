# Lekcja 9.3 — `requests`: pobieranie danych z sieci

## Cel
Po lekcji uczeń:
- Wysyła żądanie GET do API: `requests.get(url)`
- Czyta status code i body (`r.status_code`, `r.json()`)
- Wysyła parametry zapytania i nagłówki
- Obsługuje błędy sieci
- Wie o `httpx` jako współczesnej alternatywie

## Krok 1 — Zakotwiczenie (3 min)
**Pytanie wejściowe:**
> "Wpisujesz adres w przeglądarce — co się dzieje 'pod spodem' żeby strona się pokazała?"

**Co chcesz usłyszeć:** komputer wysyła żądanie do serwera, serwer odpowiada (HTML, dane), przeglądarka rysuje. Python może robić to samo — bez przeglądarki, programowo. To **API**.

## Krok 2 — Mostek (5 min)
**Mostek:** "API to 'interfejs dla programów' — strony udostępniają dane w prostym formacie (zwykle JSON). Python pobiera, parsuje, używa. Biblioteka `requests` to **standard** dla HTTP w Pythonie."

**Minimalny przykład:**
```python
import requests

r = requests.get("https://api.github.com")
print(r.status_code)        # 200 = OK
print(r.json())              # dane jako słownik Pythona
```

**Pytania:**
- "Co robi `requests.get`?" (wysyła żądanie HTTP GET)
- "Co znaczy `200`?" (status OK — wszystko poszło dobrze)

## Krok 3 — Eksperyment (15-20 min)

**Najpierw:** uczeń ma aktywny venv z `pip install requests` (z lekcji 9.2). Jeśli nie — zrób.

**1. Prosty GET:**
```python
import requests

r = requests.get("https://httpbin.org/get")
print(r.status_code)
print(r.text)           # raw odpowiedź jako string
print(r.json())         # sparsowane JSON jako dict
```

**2. Status code:**
```python
r = requests.get("https://httpbin.org/status/404")
print(r.status_code)    # 404
print(r.ok)             # False
```
Status code'y do zapamiętania:
- **200** OK
- **201** Created (po POST)
- **400** Bad Request (twoje dane były złe)
- **401** Unauthorized
- **404** Not Found
- **500** Server Error

**3. Parametry zapytania:**
```python
params = {"q": "python", "limit": 5}
r = requests.get("https://api.github.com/search/repositories", params=params)
print(r.url)            # zobacz, jak Python sklejał URL
dane = r.json()
print(f"Znaleziono: {dane['total_count']}")
for repo in dane["items"][:5]:
    print(repo["full_name"], "★", repo["stargazers_count"])
```

**4. Nagłówki (np. user agent, auth):**
```python
headers = {"User-Agent": "Moj-Skrypt/1.0"}
r = requests.get("https://api.github.com", headers=headers)
```

**5. POST (wysyłanie danych):**
```python
dane = {"imie": "Anna", "wiek": 30}
r = requests.post("https://httpbin.org/post", json=dane)
print(r.json()["json"])    # serwer odbił dane z powrotem
```

**6. Obsługa błędów:**
```python
try:
    r = requests.get("https://nieistniejacy-serwis.xyz/x", timeout=5)
    r.raise_for_status()    # rzuca błąd jeśli status >= 400
    print(r.json())
except requests.Timeout:
    print("Timeout — serwer się nie odezwał w 5 sekund")
except requests.ConnectionError:
    print("Brak połączenia")
except requests.HTTPError as e:
    print(f"HTTP błąd: {e}")
```

## Krok 4 — Pogłębienie (15 min)

**Praktyczny przykład — pogoda z API:**
```python
import requests

def pobierz_pogode(miasto):
    # API publiczne, bez klucza (jako przykład):
    url = f"https://wttr.in/{miasto}?format=j1"
    r = requests.get(url, timeout=10)
    r.raise_for_status()
    dane = r.json()
    aktualna = dane["current_condition"][0]
    return {
        "temperatura": aktualna["temp_C"],
        "wilgotnosc": aktualna["humidity"],
        "opis": aktualna["weatherDesc"][0]["value"],
    }

pogoda = pobierz_pogode("Warsaw")
print(pogoda)
```

**Sesje (zaawansowane):**
```python
with requests.Session() as s:
    s.headers.update({"Authorization": "Bearer XYZ"})
    r1 = s.get("https://api/...")
    r2 = s.get("https://api/...")
    # Wszystkie żądania w sesji dzielą nagłówki, cookies, connection pool
```

**Pobieranie pliku binarnego:**
```python
r = requests.get("https://example.com/obraz.png")
with open("obraz.png", "wb") as f:
    f.write(r.content)        # .content = bytes, .text = string
```

**Streamowanie dużych plików:**
```python
with requests.get("https://big-file", stream=True) as r:
    with open("big.bin", "wb") as f:
        for chunk in r.iter_content(chunk_size=8192):
            f.write(chunk)
```

**Typowe błędy do sprowokowania:**
- Brak `timeout` → kod może wisieć w nieskończoność na wolnym API. **Zawsze daj timeout**.
- Próba `r.json()` na nie-JSON odpowiedzi → `json.JSONDecodeError`.
- Status 4xx/5xx → ale `r.json()` nie rzuca samo. Trzeba `r.raise_for_status()`.
- Rate limiting (zbyt wiele żądań) → status 429.

→ Skill `cwiczenie`. Temat: "API". Sugerowane zadania:
- 🔥 Użyj `https://api.github.com/users/<nazwa>` — pobierz dane konta GitHub i wypisz `name`, `public_repos`, `created_at`.
- ⭐ Użyj `https://api.publicapis.org/entries` — pobierz listę publicznych API, wypisz 10 pierwszych po nazwie.
- ⚡ Stwórz funkcję `pobierz_temperature(miasto: str) -> float` używając `https://wttr.in/{miasto}?format=j1`. Obsłuż timeout i błąd nazwy miasta. Test `pytest` z `mock` (zaawansowane) lub manualnie.

## Pułapki
- **Brak `timeout`** — kod może wisieć minutami.
- **`r.json()` na nie-JSON** → JSONDecodeError. Sprawdź `r.headers.get('content-type')`.
- **Hardcoded klucze API w kodzie** — to **security risk**. Używaj zmiennych środowiskowych: `os.environ.get("API_KEY")`.
- **Rate limit** — niektóre API mają limity. Sprawdź `r.headers.get('X-RateLimit-Remaining')`.
- **Niezabezpieczone HTTP** — używaj `https://`, nie `http://`.

## Aktualizacja 2026 (z `AKTUALIZACJE.md`)
- **`httpx`** — alternatywa dla `requests`, async-friendly, kompatybilne API:
```python
import httpx
r = httpx.get("https://api.github.com")
print(r.json())
```
W nowym kodzie często wybierany, zwłaszcza dla async.
- **`urllib.request` (stdlib)** — działa, ale brzydsze API. Nie polecaj początkującym.
- **WebSockety / streaming** — `requests` nie wspiera; `httpx` częściowo; pełne: `websockets`.
- **Bezpieczeństwo:** zawsze HTTPS, nigdy nie commituj kluczy API.
