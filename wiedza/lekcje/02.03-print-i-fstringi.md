# Lekcja 2.3 — `print` i f-stringi

## Cel
Po lekcji uczeń:
- Łączy zmienne i tekst w jednym wypisaniu (f-string)
- Formatuje liczby: liczba miejsc po przecinku, padding
- Wie o `input()` — czytanie tekstu od użytkownika
- Rozumie, że `input()` zawsze zwraca string

## Krok 1 — Zakotwiczenie (3 min)
**Pytanie wejściowe:**
> "Chcesz powiedzieć: 'Anna ma 30 lat'. Ale 'Anna' to imię, a '30' to liczba — z różnych miejsc. Jakbyś to skleił w jedno zdanie, gdyby ktoś dyktował Ci po kawałku?"

**Co chcesz usłyszeć:** trzeba mieć szablon, do którego wstawiasz "dziury" — "{} ma {} lat" → "Anna" i "30".

## Krok 2 — Mostek (5 min)
**Mostek:** "Dokładnie tak działają **f-stringi** w Pythonie. To tekst z dziurami {nazwa_zmiennej}, a Python sam wstawia wartości."

**Minimalny przykład:**
```python
imie = "Anna"
wiek = 30
print(f"{imie} ma {wiek} lat")  # Anna ma 30 lat
```

**Pytania:**
- "Co robi mała `f` przed cudzysłowem?"
- "Co byłoby, gdybym napisał bez `f`?" → Niech uczeń sprawdzi: `"{imie} ma {wiek} lat"` wypisze **dosłownie**, bez podstawienia.

## Krok 3 — Eksperyment (15 min)
1. Stwórz zmienne `imie`, `wiek`, `miasto`. Złóż f-stringa: "Jestem [imie], mam [wiek] lat, z [miasto]."
2. Wewnątrz nawiasów `{}` możesz **liczyć**: `f"{wiek + 1}"` → wiek powiększony o 1
3. Wewnątrz może być wywołanie funkcji: `f"{imie.upper()}"` → "ANNA"
4. **Formatowanie liczb:** `f"{3.14159:.2f}"` → "3.14" (2 miejsca po przecinku)
5. **Padding:** `f"{42:>5}"` → "   42" (wyrównanie do prawej w 5 znakach)

**Po każdym pytaj:** "Co Python wypisał? Spodziewałeś się?"

## Krok 4 — Pogłębienie (10 min)

**`input()` — czytanie od użytkownika:**
```python
imie = input("Jak masz na imię? ")
print(f"Cześć, {imie}!")
```

**Eksperyment:** uczeń uruchamia, wpisuje imię, dostaje powitanie.

**Pułapka 1:**
```python
wiek = input("Ile masz lat? ")
print(f"Za rok będziesz mieć {wiek + 1}")  # BŁĄD!
```
`input()` **zawsze zwraca string**, nawet gdy wpiszesz cyfry! `"30" + 1` to TypeError. Trzeba konwertować:
```python
wiek = int(input("Ile masz lat? "))
print(f"Za rok będziesz mieć {wiek + 1}")
```

**Stare formatowanie (do rozpoznawania, NIE używania w nowym kodzie):**
- `.format()`: `"{} ma {} lat".format(imie, wiek)`
- Operator `%`: `"%s ma %d lat" % (imie, wiek)` (jak printf w C)

Wytłumacz: w starych kodach to zobaczysz. W nowym pisz **tylko f-stringi**.

## Krok 5 — Ćwiczenie
→ Skill `cwiczenie`. Temat: "dialog z użytkownikiem". Sugerowane zadania:
- 🔥 Zapytaj o imię, przywitaj
- ⭐ Zapytaj o dwie liczby, wypisz sumę (pamiętaj o `int()`!)
- ⚡ "Kalkulator wieku" — zapytaj o rok urodzenia, wypisz wiek (przyjmij że dziś jest 2026; wynik z formatem: "Masz X lat")

## Pułapki
- **`input()` zwraca string** — to ZAWSZE wymaga konwersji, jeśli liczysz. Najczęstszy błąd początkujących.
- **Pusty input (Enter)** — `input()` zwraca pusty string `""`, nie `None`.
- **Brak `f` przed cudzysłowem** — Python wypisze dosłownie `{imie}`, nie podstawi wartości. Sprawdź dokładnie.
- **`{` lub `}` jako zwykły znak w f-stringu** — trzeba podwoić: `f"{{nic}}"` → "{nic}".
- **Cudzysłowy w cudzysłowach** w starszym Pythonie (przed 3.12) — trzeba było mieszać `'` i `"`. Od 3.12 możesz cokolwiek.

## Aktualizacja 2026 (z `AKTUALIZACJE.md`)
- **f-string PEP 701 (3.12+)** — wszystkie poprzednie ograniczenia padły. Można:
  - Te same cudzysłowy w środku: `f"Cześć {imie if imie != "" else "nieznajomy"}"`
  - Wielolinijkowe f-stringi w trojakich cudzysłowach
- **f-string z `=`** (3.8+, debugging idiom): `print(f"{wiek=}")` → wypisze `wiek=30`. Bardzo wygodne przy debugowaniu.

## Notatki tutora
- **Pokaż `f"{wiek=}"` jako "magiczny trik"** — uczeń się zachwyci, bo to oszczędza pisanie.
- Jeśli uczeń pyta o `.format()` — wytłumacz, że to historia, ale zostaw na "kiedyś zobaczysz w starych kodach".
- **NIE wprowadzaj** placeholderów typu `{0}`, `{1}` — to anty-idiom w f-stringach.
