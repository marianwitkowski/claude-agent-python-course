# Lekcja 10.1 — `lambda` i funkcje wyższego rzędu

## Cel
Po lekcji uczeń:
- Pisze `lambda x: x * 2`
- Wie, że lambda to "krótka funkcja jednorazowego użytku"
- Przekazuje funkcję jako argument do innej funkcji
- Wie KIEDY lambda jest OK, a kiedy lepiej zwykły `def`

## Krok 1 — Zakotwiczenie (5 min)
**Pytanie wejściowe:**
> "Idziesz do supermarketu z listą. Czy zapisałeś sobie tę listę z nazwą i opisem 'Lista zakupów na 28 maja, sklep TESCO, godzina 17'? Czy po prostu wpisałeś na kartce?"

**Co chcesz usłyszeć:** zwykle wpisałeś — to **jednorazowa rzecz**, nie potrzebuje nazwy. Tak samo z funkcjami — czasem funkcja jest jednorazowa, drobna, nie potrzebuje nazwy.

## Krok 2 — Mostek (5 min)
**Mostek:** "`lambda` to **funkcja anonimowa** — pisana w jednej linii, bez nazwy. Używamy gdy potrzebujemy krótkiej funkcji raz, np. żeby przekazać jako argument do `sorted` czy `filter`."

**Minimalny przykład:**
```python
# klasyczny def:
def podwoj(x):
    return x * 2

# lambda — to samo, w jednej linii:
podwoj = lambda x: x * 2

print(podwoj(5))  # 10
```

**Pytania:**
- "Co `lambda x: x * 2` znaczy słowami?"
- "Czy widzisz `return`? Skąd Python wie co zwrócić?" (po dwukropku — wyrażenie zwracane automatycznie)

## Krok 3 — Eksperyment (15 min)

**1. Proste lambdy:**
```python
kwadrat = lambda x: x ** 2
print(kwadrat(4))    # 16

dodaj = lambda a, b: a + b
print(dodaj(3, 7))   # 10

parzysta = lambda x: x % 2 == 0
print(parzysta(4))   # True
```

**2. Lambda jako argument funkcji (DRUGI typowy use):**
```python
liczby = [3, 1, 4, 1, 5, 9, 2, 6]

# sorted() przyjmuje key= — funkcję mówiącą "po czym sortować":
print(sorted(liczby))                     # [1,1,2,3,4,5,6,9]
print(sorted(liczby, key=lambda x: -x))    # malejąco: [9,6,5,4,3,2,1,1]

# sortowanie listy stringów po długości:
imiona = ["Anna", "Borys", "Cecylia", "Ed"]
print(sorted(imiona, key=lambda s: len(s)))  # ['Ed','Anna','Borys','Cecylia']

# sortowanie słownika po wartości:
oceny = {"matma": 4, "polski": 5, "chemia": 3}
posortowane = sorted(oceny.items(), key=lambda para: para[1])
print(posortowane)
```

**3. Funkcje wyższego rzędu — przyjmują/zwracają funkcje:**
```python
def zastosuj(funkcja, x):
    return funkcja(x)

print(zastosuj(lambda x: x * 3, 5))   # 15
print(zastosuj(kwadrat, 4))            # 16

# funkcja zwracająca funkcję:
def mnoznik(n):
    return lambda x: x * n

razy3 = mnoznik(3)
razy5 = mnoznik(5)
print(razy3(10))  # 30
print(razy5(10))  # 50
```

**Po każdym pytaj:** "Co się stało? Co `lambda` tu robi?"

## Krok 4 — Pogłębienie (10 min)

**Kiedy lambda OK:**
- Krótka, jednorazowa (1 linia)
- Jako argument: `sorted(...)`, `filter(...)`, `map(...)`
- Pasuje wzrokowo (czytelne)

**Kiedy WOLNIEJ — używaj `def`:**
- Dłuższa niż 1 linia logiki
- Używana w wielu miejscach (daj nazwę!)
- Skomplikowana — `def` z nazwą **dokumentuje** intencję

**Anty-idiomy lamba:**
```python
# źle:
x = lambda: print("hej")     # po co nie def?

# zamiast:
def hej():
    print("hej")

# źle:
sorted(dane, key=lambda x: x if x > 0 else -x)
# zamiast (czytelniej):
def abs_value(x):
    return x if x > 0 else -x
sorted(dane, key=abs_value)
```

**`def` vs `lambda` — to samo dla Pythona:**
```python
def f(x): return x * 2
g = lambda x: x * 2

print(f(5), g(5))   # 10 10
print(type(f), type(g))  # function, function
```
Lambda to **tylko skrót składniowy**, nic więcej.

**Typowe błędy do sprowokowania:**
- Wieloliniowa lambda → SyntaxError (nie da się — lambda to jedno wyrażenie).
- Statement (`if`/`for`) w lambdzie → SyntaxError. Lambda przyjmuje tylko wyrażenia.
- Pisanie skomplikowanej lambdy "jak w funkcji" → kod nieczytelny. Niech uczeń sam zobaczy na własnym przykładzie.

## Krok 5 — Ćwiczenie
→ Skill `cwiczenie`. Temat: "lambda". Sugerowane zadania:
- 🔥 Lista wieków `[15, 22, 8, 40, 19]`. Posortuj malejąco używając `sorted` + `lambda`.
- ⭐ Lista słowników `osoby = [{"imie": "Anna", "wiek": 30}, ...]`. Posortuj po wieku rosnąco i wypisz.
- ⚡ Funkcja `oblicz(operacja, a, b)` przyjmująca lambdę. Wywołaj dla dodawania, mnożenia, modulo, średniej `(a + b) / 2`.

## Pułapki
- **Lambda to JEDNO wyrażenie** — żadnych `if x: ...; else: ...; return ...`.
- **Lambda przypisana do zmiennej** to często anty-idiom — pisz po prostu `def`.
- **`lambda x, y: ...`** wymaga przecinka między argumentami; **`lambda x y: ...`** to SyntaxError.
- **Late binding w pętli z lambdami** (zaawansowane):
```python
fs = [lambda: i for i in range(3)]
print([f() for f in fs])   # [2, 2, 2] — NIE [0,1,2]!
```
Lambda widzi `i` w momencie wywołania, nie tworzenia. Wzmiankuj, ale to detal.

## Notatki tutora
- **Lambda jest niedoceniana** — pokaż konkretne use cases (sorted, filter, map), nie abstrakcyjne `f = lambda x: x + 1`.
- **Nie wymuszaj** lambd — `def` jest często lepszy. Lambda to **opcja**, nie cnota.
- Jeśli uczeń pisze złożoną lambdę — zaproponuj przepisanie na `def`. Niech sam oceni czytelność.
