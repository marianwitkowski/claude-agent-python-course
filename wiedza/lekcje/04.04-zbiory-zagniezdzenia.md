# Lekcja 4.4 — Zbiory i zagnieżdżone struktury

## Cel
Po lekcji uczeń:
- Tworzy zbiór `{1, 2, 3}`, wie że elementy są **unikalne**
- Używa operacji zbiorów: `|` (suma), `&` (przecięcie), `-` (różnica), `^` (różnica symetryczna)
- Wie, kiedy zbiór lepszy od listy (sprawdzenie unikalności, szybkie `in`)
- Pracuje z zagnieżdżonymi strukturami (lista słowników, słownik list)

## Krok 1 — Zakotwiczenie (3 min)
**Pytanie wejściowe:**
> "Robisz listę osób zaproszonych na imprezę. Czy ważna jest kolejność? Czy ktoś może być wpisany dwa razy?"

**Co chcesz usłyszeć:** kolejność nieważna, duplikaty bez sensu. To **zbiór** — unikalność, brak kolejności.

## Krok 2 — Mostek (5 min)
**Mostek:** "Zbiór (`set`) to kolekcja, w której **każdy element może być tylko raz** i **nie ma kolejności**. Idealny do unikalnych wartości."

**Minimalny przykład:**
```python
goscie = {"Anna", "Borys", "Cecylia", "Anna"}
print(goscie)  # {'Anna', 'Borys', 'Cecylia'} — Anna raz!
```

**Pytania:**
- "Co się stało z duplikatem 'Anna'?"
- "Czy widzisz numerację jak w liście?" (nie — `goscie[0]` byłby błędem)

## Krok 3 — Eksperyment (15 min)
1. **Tworzenie:**
```python
a = {1, 2, 3}
b = set([1, 2, 2, 3])  # z listy → automatycznie usuwa duplikaty
c = set()              # pusty zbiór (uwaga: {} to słownik!)
```
2. **Dodawanie / usuwanie:** `a.add(4)`, `a.remove(1)`, `a.discard(99)` (bezpieczne)
3. **Sprawdzenie obecności:** `2 in a` → True
4. **Długość:** `len(a)`
5. **Operacje zbiorów:**
```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
print(a | b)   # {1,2,3,4,5,6} — suma (union)
print(a & b)   # {3,4} — przecięcie (intersection)
print(a - b)   # {1,2} — różnica
print(a ^ b)   # {1,2,5,6} — różnica symetryczna (XOR)
```
6. **Iteracja:** `for x in a: print(x)` — kolejność może być różna.

**Po każdym pytaj:** "Co Python pokazał? Zgadzasz się z wynikiem matematycznym?"

**Praktyczne użycia zbiorów:**
- **Usuwanie duplikatów z listy:** `lista_bez_duplikatow = list(set(lista))`
- **Sprawdzenie czy lista ma duplikaty:** `len(lista) != len(set(lista))`
- **Wspólne elementy dwóch list:** `set(lista1) & set(lista2)`

## Krok 4 — Pogłębienie — zagnieżdżenia (15 min)

**Lista słowników** — częsta forma danych (np. tabela):
```python
uczniowie = [
    {"imie": "Anna", "wiek": 14, "ocena": 5},
    {"imie": "Borys", "wiek": 15, "ocena": 4},
    {"imie": "Cecylia", "wiek": 14, "ocena": 5},
]

# Wypisz wszystkich:
for u in uczniowie:
    print(f"{u['imie']}, lat {u['wiek']}, ocena {u['ocena']}")

# Średnia ocen:
suma = 0
for u in uczniowie:
    suma += u["ocena"]
print(f"Średnia: {suma / len(uczniowie)}")
```

**Słownik list** — np. grupowanie:
```python
oceny_klas = {
    "matematyka": [5, 4, 3, 5, 4],
    "polski": [4, 4, 5, 3, 5],
}

# Średnia matematyki:
mat = oceny_klas["matematyka"]
print(sum(mat) / len(mat))
```

**Słownik słowników:**
```python
firma = {
    "Anna": {"stanowisko": "kierownik", "pensja": 8000},
    "Borys": {"stanowisko": "stażysta", "pensja": 3000},
}
print(firma["Anna"]["pensja"])  # 8000
```

**Typowe błędy do sprowokowania:**
- `{}` to **słownik**, NIE zbiór. Pusty zbiór: `set()`.
- `set([1,2,3])` działa; `set(1,2,3)` nie (set przyjmuje **jeden** iterable).
- Próba `set` z listą list → TypeError (lista jest mutowalna, niehashable). Krotki działają: `set([(1,2), (3,4)])`.

## Krok 5 — Ćwiczenie
→ Skill `cwiczenie`. Temat: "kolekcje w praktyce". Sugerowane zadania:
- 🔥 Stwórz dwa zbiory: ulubione owoce ty / kolega. Wypisz wspólne (`&`) i tylko twoje (`-`).
- ⭐ Lista 6 imion z duplikatem. Wypisz: ile unikalnych, ile duplikatów, lista unikalnych.
- ⚡ Lista słowników: 5 uczniów (imie, wiek, ocena). Znajdź ucznia z najwyższą oceną. Wypisz średnią. Wypisz unikalne wieki (jako zbiór).

## Pułapki
- **`{}` to słownik, nie pusty zbiór.** `set()` to pusty zbiór.
- **Brak indeksowania** — zbiór nie ma `set[0]`. Bo nie ma kolejności.
- **Elementy muszą być niemutowalne** (hashable): int, str, tuple. Lista nie.
- **Zbiory są szybkie dla `in`** — sprawdzenie `x in zbior` to O(1), w liście O(n). Ważne przy dużych danych.
- **Dostęp do zagnieżdżonej struktury** wymaga uważności: `lista[2]["klucz"]["pole"]` — łatwo o `KeyError` lub `IndexError`.

## Notatki tutora
- **Zbiory są niedoceniane przez początkujących** — pokaż konkrety: usuwanie duplikatów to **jedna linijka**.
- **Zagnieżdżone struktury to przedsmak prawdziwych danych** (JSON, API). Poświęć trochę czasu na "jak się do tego dostać".
- Jeśli uczeń pyta "po co to wszystko, lista wystarczy" — odpowiedz: każda struktura ma swój sweet spot. Wybór dobrej oszczędza Ci kodu i błędów.
- **Nie wchodź w `frozenset`** ani **`OrderedDict`** — to detale.
