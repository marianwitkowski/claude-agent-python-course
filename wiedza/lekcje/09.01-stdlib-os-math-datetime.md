# Lekcja 9.1 — Standardowa biblioteka: `os`, `math`, `datetime`, `pathlib`

## Cel
Po lekcji uczeń:
- Wie, że "stdlib" = zestaw modułów wbudowanych (bez instalacji)
- Używa `math` (operacje matematyczne), `datetime` (daty), `pathlib` (ścieżki)
- Zna `random`, `json`, `csv` (wzmianki)
- Wie gdzie szukać reszty: docs.python.org

## Krok 1 — Zakotwiczenie (3 min)
**Pytanie wejściowe:**
> "Kupujesz nowy laptop. Czy musisz instalować notatnik, kalkulator, podstawową przeglądarkę plików?"

**Co chcesz usłyszeć:** nie — to wszystko już jest w systemie. Tak samo z Pythonem: **stdlib** to "baterie w zestawie" — moduły, które masz od razu, bez `pip install`.

## Krok 2 — Mostek (5 min)
**Mostek:** "**Standardowa biblioteka (stdlib)** to setki modułów, które przychodzą z Pythonem. Daty, ścieżki, matematyka, sieć, kompresja, JSON... Większość codziennych zadań robisz z nich, **bez instalowania niczego**."

**Minimalny przykład:**
```python
import math
from datetime import date

print(math.sqrt(144))            # 12.0
print(math.pi)                    # 3.14159...
print(date.today())               # 2026-05-28
print(date.today().year)          # 2026
```

## Krok 3 — Eksperyment (20 min)

### `math`:
```python
import math

print(math.sqrt(16))      # pierwiastek
print(math.floor(3.7))    # 3 (zaokrąglenie w dół)
print(math.ceil(3.2))     # 4 (zaokrąglenie w górę)
print(math.pi)            # π
print(math.e)             # e
print(math.factorial(5))  # 120
print(math.log(100, 10))  # log10(100) = 2.0
print(math.sin(math.pi/2)) # 1.0
```

### `random`:
```python
import random

print(random.randint(1, 100))     # losowa int 1-100 (włącznie)
print(random.random())            # float 0.0-1.0
print(random.choice(["A","B","C"])) # losowy element listy
random.shuffle([1,2,3,4,5])       # tasowanie (modyfikuje!)
```

### `datetime`:
```python
from datetime import date, datetime, timedelta

print(date.today())                  # dzisiaj: 2026-05-28
print(datetime.now())                # data i godzina

# Tworzenie:
dzien = date(1990, 6, 15)
print(dzien.year, dzien.month, dzien.day)

# Różnice:
ile_dni = date.today() - dzien
print(ile_dni.days)                  # liczba dni od urodzin

# Format:
print(dzien.strftime("%d.%m.%Y"))    # 15.06.1990
print(date.today() + timedelta(days=30))  # za 30 dni
```

### `pathlib` (współczesny standard):
```python
from pathlib import Path

p = Path("test.txt")
print(p.exists())                    # False (jeśli nie ma)
p.write_text("Cześć\n", encoding="utf-8")
print(p.read_text(encoding="utf-8"))

# Operacje na ścieżkach:
katalog = Path("dane")
katalog.mkdir(exist_ok=True)         # stwórz, OK jeśli istnieje
plik = katalog / "raport.txt"         # / to operator łączenia ścieżek!
plik.write_text("treść\n", encoding="utf-8")

print(plik.parent)        # dane
print(plik.name)          # raport.txt
print(plik.stem)          # raport (bez rozszerzenia)
print(plik.suffix)        # .txt

# Iteracja po katalogu:
for f in katalog.iterdir():
    print(f)
```

**Po każdym pytaj:** "Co ten moduł ci dał? Jak byś to napisał bez niego?"

## Krok 4 — Pogłębienie (15 min)

### `os` — system operacyjny (klasyka, ale dziś `pathlib` zwykle lepszy):
```python
import os

print(os.getcwd())            # bieżący katalog
os.chdir("..")                # zmiana katalogu
print(os.listdir("."))        # lista plików
print(os.path.exists("test.txt"))  # czy istnieje
print(os.environ.get("HOME")) # zmienna środowiskowa
```

### `json` — wzmianka (szczegóły w 9.2 lub projekcie):
```python
import json

dane = {"imie": "Anna", "wiek": 30, "lubi": ["pizza", "kawa"]}

# Do stringa:
tekst = json.dumps(dane, ensure_ascii=False, indent=2)
print(tekst)

# Z powrotem:
obiekt = json.loads(tekst)
print(obiekt["imie"])

# Z/do pliku:
with open("dane.json", "w", encoding="utf-8") as f:
    json.dump(dane, f, ensure_ascii=False, indent=2)

with open("dane.json", "r", encoding="utf-8") as f:
    wczytane = json.load(f)
```

### `csv` — wzmianka:
```python
import csv

with open("dane.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["imie", "wiek"])
    writer.writerow(["Anna", 30])
    writer.writerow(["Borys", 25])
```

## Pułapki
- **`import os` vs `import os.path`** — `os.path` to podmoduł. `import os` wystarczy do `os.path.join`.
- **`os.path` vs `pathlib`** — robią to samo; pathlib jest **nowsze i czytelniejsze**. W 2026 wybieraj `pathlib`.
- **`json.dumps` bez `ensure_ascii=False`** — polskie znaki kodują się jako `ą`. Zawsze daj `ensure_ascii=False, indent=2` dla czytelności.
- **`datetime` vs `date`** — `datetime` ma datę I godzinę, `date` tylko datę.
- **`random.seed(...)`** — ustawia ziarno, dzięki czemu losowe wartości są powtarzalne. Przydatne do testów.

## Aktualizacja 2026 (z `AKTUALIZACJE.md`)
- **`pathlib` zawsze preferuj** nad `os.path`. Czytelniejsze, obiektowe.
- **`tomllib` w stdlib** (3.11+): `import tomllib`, `tomllib.load(open("conf.toml", "rb"))`.
- **`zoneinfo`** (3.9+) — strefy czasowe w stdlib: `from zoneinfo import ZoneInfo; datetime.now(ZoneInfo("Europe/Warsaw"))`.
- **`dataclasses.dataclass`** + **`json`** — można serializować dataclass do JSON za pomocą `dataclasses.asdict(obj)`.

## Notatki tutora
- **Nie próbuj nauczyć wszystkiego** — stdlib ma setki modułów. Pokaż 4-5 najczęstszych + wskaż gdzie szukać reszty.
- **`pathlib` to nowoczesność** — zostaw `os.path` jako "historię, którą zobaczysz w starym kodzie".
- **Daty są zawsze trudne** — strefy czasowe, formaty, parsing. Niech uczeń poczuje smak, nie wymagaj mistrzostwa.
