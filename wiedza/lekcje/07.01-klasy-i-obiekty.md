# Lekcja 7.1 — Klasa i obiekt: czym to różni się od dict

## Cel
Po lekcji uczeń:
- Definiuje klasę z `__init__`, atrybutami i metodami
- Tworzy obiekty (instancje) klasy
- Rozumie różnicę: klasa = przepis, obiekt = konkretny egzemplarz
- Wie kiedy klasa jest lepsza niż słownik (gdy są **zachowania** + dane)

## Krok 1 — Zakotwiczenie (5 min)
**Pytanie wejściowe:**
> "Co to jest 'pies'? Wskaż mi konkretnego psa, którego znasz."

**Co chcesz usłyszeć:** "Pies" to **kategoria/gatunek** — abstrakcyjny opis. "Burek sąsiadów" to **konkretny pies** — egzemplarz. Pies ma cechy (kolor, rasa) i zachowania (szczeka, biega). Każdy konkretny pies ma swoje wartości tych cech.

## Krok 2 — Mostek (5 min)
**Mostek:** "Dokładnie tak: **klasa** to definicja (jak 'pies' ogólnie), **obiekt** to konkretny egzemplarz (Burek). Klasa opisuje, jakie **atrybuty** ma obiekt (cechy) i jakie **metody** (zachowania)."

**Minimalny przykład:**
```python
class Pies:
    def __init__(self, imie, rasa):
        self.imie = imie
        self.rasa = rasa

    def szczekaj(self):
        print(f"{self.imie}: Hau hau!")

burek = Pies("Burek", "mieszaniec")
azor = Pies("Azor", "owczarek")

burek.szczekaj()  # Burek: Hau hau!
azor.szczekaj()   # Azor: Hau hau!
```

**Pytania:**
- "Co tu jest klasą? Co obiektem?"
- "Co robi `__init__`?" (konstruktor — wywołuje się przy tworzeniu obiektu)
- "Co znaczy `self`?" (referencja do *tego konkretnego* obiektu)
- "Czemu `Pies("Burek", ...)` zamiast `Pies(self, "Burek", ...)`? — `self` Python wstawia sam.

## Krok 3 — Eksperyment (15-20 min)

1. **Stwórz prostą klasę:**
```python
class Osoba:
    def __init__(self, imie, wiek):
        self.imie = imie
        self.wiek = wiek

    def przedstaw_sie(self):
        print(f"Cześć, jestem {self.imie}, mam {self.wiek} lat.")

anna = Osoba("Anna", 30)
anna.przedstaw_sie()
print(anna.imie)        # Anna — bezpośredni dostęp do atrybutu
print(anna.wiek)        # 30
```

2. **Wiele obiektów tej samej klasy:**
```python
anna = Osoba("Anna", 30)
borys = Osoba("Borys", 25)
anna.przedstaw_sie()
borys.przedstaw_sie()
```

3. **Modyfikacja atrybutu:**
```python
anna.wiek = 31  # urodziny
anna.przedstaw_sie()
```

4. **Metody mogą używać innych metod:**
```python
class Konto:
    def __init__(self, wlasciciel, saldo=0):
        self.wlasciciel = wlasciciel
        self.saldo = saldo

    def wplac(self, kwota):
        self.saldo += kwota
        print(f"Wpłacono {kwota}. Saldo: {self.saldo}")

    def wyplac(self, kwota):
        if kwota > self.saldo:
            print("Brak środków!")
            return
        self.saldo -= kwota
        print(f"Wypłacono {kwota}. Saldo: {self.saldo}")

konto = Konto("Anna", 100)
konto.wplac(50)
konto.wyplac(30)
konto.wyplac(200)  # brak środków
```

**Po każdym pytaj:** "Co się stało? Co `self` robił?"

## Krok 4 — Pogłębienie (15 min)

**Klasa vs słownik — porównanie:**
```python
# słownik:
osoba_dict = {"imie": "Anna", "wiek": 30}
# żeby coś "zrobić" musisz pisać:
print(f"{osoba_dict['imie']} ma {osoba_dict['wiek']} lat")

# klasa:
class Osoba:
    def __init__(self, imie, wiek):
        self.imie = imie
        self.wiek = wiek
    def opis(self):
        return f"{self.imie} ma {self.wiek} lat"

osoba = Osoba("Anna", 30)
print(osoba.opis())  # zachowanie "wbudowane" w obiekt
```
**Kiedy klasa:**
- Gdy masz dane + powiązane **zachowania** (operacje)
- Gdy masz wiele takich samych "rzeczy" (Konto1, Konto2, Konto3 ...)
- Gdy chcesz modelować świat (Klient, Produkt, Zamówienie)

**Kiedy słownik:**
- Gdy dane są "wolne", bez ustalonej struktury (np. konfiguracja)
- Gdy klucze są dynamiczne (np. liczenie wystąpień słów)
- Gdy ładujesz JSON

**`__str__` — kontroluj jak obiekt wygląda przy `print`:**
```python
class Osoba:
    def __init__(self, imie, wiek):
        self.imie = imie
        self.wiek = wiek

    def __str__(self):
        return f"Osoba({self.imie}, {self.wiek} lat)"

print(Osoba("Anna", 30))  # Osoba(Anna, 30 lat) — zamiast <Osoba object at 0x...>
```

**Typowe błędy do sprowokowania:**
- Zapomniany `self` w `def metoda(self):` → `TypeError: metoda() takes 0 positional arguments but 1 was given`.
- `self.x = ...` zamiast `x = ...` w `__init__` → atrybut nie zapisze się w obiekcie.
- Wywołanie metody bez nawiasów: `anna.przedstaw_sie` → zwraca obiekt metody, nie wywołuje.

## Krok 5 — Ćwiczenie
→ Skill `cwiczenie`. Temat: "pierwsze klasy". Sugerowane zadania:
- 🔥 Klasa `Kot` z atrybutami `imie`, `wiek` i metodą `miaucz()`. Stwórz 2 koty.
- ⭐ Klasa `Konto` — z `wlasciciel`, `saldo`, metodami `wplac`, `wyplac`, `stan`. Symuluj 5 operacji.
- ⚡ Klasa `Prostokat` z `szerokosc`, `wysokosc`. Metody: `pole()`, `obwod()`, `czy_kwadrat()`. Stwórz 3 obiekty, wypisz pole każdego.

## Pułapki
- **Zapomniany `self`** w definicji metody → `TypeError`.
- **`self.x = y` vs `x = y`** w metodzie — pierwsze tworzy atrybut, drugie tworzy lokalną zmienną.
- **CamelCase dla klas** (`Osoba`, `Konto`), **snake_case dla metod** (`przedstaw_sie`).
- **Wywołanie bez `()`** — `anna.przedstaw_sie` to **referencja do metody**, nie wywołanie.
- **Klasa to nie obiekt** — `Osoba` to klasa, `Osoba(...)` to wywołanie tworzące obiekt.

## Aktualizacja 2026 (z `AKTUALIZACJE.md`)
- **`@dataclass`** — wspomnij na koniec lekcji, szczegóły w 7.3:
```python
from dataclasses import dataclass

@dataclass
class Osoba:
    imie: str
    wiek: int

print(Osoba("Anna", 30))  # Osoba(imie='Anna', wiek=30) — automatyczny __repr__
```
Dla prostych "klas-rekordów" — krócej, czytelniej.
- **Type hints w `__init__`** — standard 2026: `def __init__(self, imie: str, wiek: int):`

## Notatki tutora
- **OOP to nowy sposób myślenia** — nie spiesz się. Niech uczeń poczuje "klasa = przepis, obiekt = egzemplarz".
- **`self` jest tajemniczy** — niech uczeń napisze 3-4 metody z `self`, intuicja przyjdzie.
- **Nie wprowadzaj jeszcze**: prywatność (`_`, `__`), `@property`, `@staticmethod`, dziedziczenie. To 7.2 i dalej.
- Pokazuj **konkretne** przykłady: Konto, Pies, Prostokąt — nie abstrakcyjne `Foo`, `Bar`.
