# Lekcja 7.3 — Wzorce i `@dataclass`

## Cel
Po lekcji uczeń:
- Używa `@dataclass` do prostych klas-rekordów
- Stosuje encapsulację — prywatne atrybuty (`_imie`), `@property`
- Rozumie pojęcie "wzorzec projektowy" na 1 przykładzie (Strategy lub Factory)
- Zna `StrEnum` i `Enum` dla enumeracji

## Krok 1 — Zakotwiczenie (3 min)
**Pytanie wejściowe:**
> "Jakie kategorie filmów rozróżniasz w kinie? Wymień kilka. Czy są stałe?"

**Co chcesz usłyszeć:** komedia, dramat, akcja, animacja, dokumentalny. Lista jest **skończona i stała**. To **enumeracja** — zbiór dopuszczalnych wartości.

## Krok 2 — Mostek (5 min)
**Mostek:** "W kodzie też mamy takie 'kategorie z listy'. Zamiast pisać `if status == 'aktywny' or status == 'nieaktywny':`, używamy `Enum` — typ z ograniczonym, nazwanym zbiorem wartości."

I dalej: "Klasy które są głównie **danymi** (mało metod, dużo atrybutów) możemy pisać krócej dzięki `@dataclass` — Python sam wygeneruje `__init__`, `__repr__`, porównywanie."

## Krok 3 — Eksperyment (15-20 min)

### `@dataclass` — krócej i czytelniej:

**Bez dataclass:**
```python
class Punkt:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __repr__(self):
        return f"Punkt(x={self.x}, y={self.y})"

    def __eq__(self, other):
        return self.x == other.x and self.y == other.y
```

**Z dataclass:**
```python
from dataclasses import dataclass

@dataclass
class Punkt:
    x: float
    y: float

p1 = Punkt(3, 4)
p2 = Punkt(3, 4)
print(p1)              # Punkt(x=3, y=4)
print(p1 == p2)        # True
```
Niech uczeń zauważy: te same możliwości, **8 linii mniej**.

### Wartości domyślne i logika:
```python
@dataclass
class Uzytkownik:
    imie: str
    email: str
    wiek: int = 0
    aktywny: bool = True

    def opis(self):
        return f"{self.imie} ({self.email})"

u = Uzytkownik("Anna", "a@a.pl")
print(u)             # Uzytkownik(imie='Anna', email='a@a.pl', wiek=0, aktywny=True)
print(u.opis())
```

### Enum — kategorie z listy:
```python
from enum import StrEnum

class StatusKonta(StrEnum):
    AKTYWNE = "aktywne"
    NIEAKTYWNE = "nieaktywne"
    ZAWIESZONE = "zawieszone"

print(StatusKonta.AKTYWNE)             # StatusKonta.AKTYWNE
print(StatusKonta.AKTYWNE == "aktywne") # True (bo StrEnum)
```
Użycie:
```python
@dataclass
class Konto:
    wlasciciel: str
    status: StatusKonta = StatusKonta.AKTYWNE

k = Konto("Anna")
print(k.status)
if k.status == StatusKonta.AKTYWNE:
    print("można korzystać")
```

### Prywatność (konwencja, nie wymuszenie):

```python
class Konto:
    def __init__(self, wlasciciel):
        self.wlasciciel = wlasciciel
        self._saldo = 0      # podkreślnik = "prywatne, nie ruszaj z zewnątrz"

    @property
    def saldo(self):
        return self._saldo

    def wplac(self, kwota):
        if kwota < 0:
            raise ValueError("kwota ujemna")
        self._saldo += kwota

k = Konto("Anna")
k.wplac(100)
print(k.saldo)         # 100 — używamy jak atrybut, choć to metoda!
# k.saldo = 999        # AttributeError (nie ma settera)
```

Wytłumacz:
- **`_atrybut`** (jeden podkreślnik) = konwencja "prywatne" (Python nie wymusza, ale programiści respektują)
- **`__atrybut`** (dwa podkreślniki) = name mangling (kompletna izolacja, ale rzadko używane)
- **`@property`** zamienia metodę w atrybut "tylko do odczytu" — używasz jak `k.saldo`, ale nie da się przypisać

## Krok 4 — Pogłębienie — wzorce (15 min)

**Wzorzec projektowy = sprawdzony schemat rozwiązania częstego problemu.**

### Wzorzec Strategy — wymienne algorytmy:
```python
class StrategiaSortowania:
    def sortuj(self, dane):
        raise NotImplementedError

class SortowanieRosnaco(StrategiaSortowania):
    def sortuj(self, dane):
        return sorted(dane)

class SortowanieMalejaco(StrategiaSortowania):
    def sortuj(self, dane):
        return sorted(dane, reverse=True)

@dataclass
class Lista:
    elementy: list
    strategia: StrategiaSortowania

    def posortowane(self):
        return self.strategia.sortuj(self.elementy)

l = Lista([3, 1, 4, 1, 5], SortowanieRosnaco())
print(l.posortowane())
l.strategia = SortowanieMalejaco()
print(l.posortowane())
```
**Esencja:** zachowanie da się **wymienić w runtime**, bez modyfikowania reszty.

### Wzorzec Factory — fabryka tworząca obiekty:
```python
class Pies:
    def opis(self): return "Pies"
class Kot:
    def opis(self): return "Kot"

def stworz_zwierze(rodzaj):
    if rodzaj == "pies":
        return Pies()
    elif rodzaj == "kot":
        return Kot()
    else:
        raise ValueError("nieznane")

z = stworz_zwierze("pies")
print(z.opis())
```
Esencja: logika tworzenia "kuli się" w jednym miejscu.

**Nie ucz wszystkich wzorców** — pokaż 1-2 jako "to istnieje". Książka GoF (Gang of Four) ma 23, ale w praktyce używa się ~5-7 regularnie.

## Krok 5 — Ćwiczenie
→ Skill `cwiczenie`. Temat: "dataclass i wzorce". Sugerowane zadania:
- 🔥 `@dataclass class Produkt: nazwa: str, cena: float`. Stwórz 3 produkty, wypisz.
- ⭐ `Enum Sezon: WIOSNA, LATO, JESIEN, ZIMA`. Klasa `Wakacje` z `sezon: Sezon`. Funkcja `polecaj(w: Wakacje)` zwracająca tekst zależny od sezonu.
- ⚡ Strategy: klasa `Cennik` z metodą `oblicz(godziny)`. Strategie: `CennikGodzinowy(stawka)`, `CennikRyczalt(kwota)`. Stwórz po jednej z każdej i policz koszt dla 8h.

## Pułapki
- **`@dataclass` wymaga type hints** — `x: int` nie `x = 5`. Bez hinta atrybut nie zostanie wciągnięty.
- **Mutowalne wartości domyślne w dataclass** — wymagają `field(default_factory=list)`:
```python
from dataclasses import field
@dataclass
class K:
    tags: list = field(default_factory=list)
```
- **`@property` bez settera** — `k.saldo = ...` rzuca błąd. To zwykle chcesz.
- **Wzorce nie są celem** — używaj, gdy problem pasuje. Nie wciskaj na siłę.

## Aktualizacja 2026 (z `AKTUALIZACJE.md`)
- **`@dataclass(frozen=True)`** — niemutowalna dataclass (jak krotka):
```python
@dataclass(frozen=True)
class Wspolrzedne:
    x: float
    y: float
```
- **`@dataclass(slots=True)`** (3.10+) — oszczędność pamięci. Zaawansowane, wzmianka.
- **`StrEnum`** (3.11+) — `Enum` którego wartości są stringami i porównują się ze stringami. Wzmiankuj jako "wygodny dla statusów".
- **Pydantic / msgspec** — biblioteki zewnętrzne dla walidacji "klas-danych". W stdlib jest dataclass; w produkcji często pydantic.

## Notatki tutora
- **`@dataclass` to ulubieniec 2026** — pokaż jak skraca kod. Uczeń zwykle "olśni".
- **Wzorce projektowe są przereklamowane** — niech uczeń zna 1-2 (Strategy, Factory), wie że istnieją inne, ale **nie obciążaj** ich nauką teraz.
- **Enkapsulacja w Pythonie to konwencja** — nie kompilator-wymuszanie jak w Javie. Powiedz to wprost.
- Nie wchodź w `__slots__`, `__new__`, metaclasses — to ekspert.
