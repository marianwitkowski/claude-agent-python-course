# Lekcja 5.1 — `def`, `return` i argumenty

## Cel
Po lekcji uczeń:
- Definiuje funkcję (`def`) z argumentami i `return`
- Wywołuje funkcję, używa zwróconej wartości
- Rozumie różnicę: argument (przy wywołaniu) vs parametr (przy definicji)
- Wie, czemu funkcje są ważne (re-użycie, czytelność)

## Krok 1 — Zakotwiczenie (5 min)
**Pytanie wejściowe:**
> "Mama prosi cię: 'zrób mi herbatę'. Jak rozumiesz to polecenie? Co byś musiał wiedzieć, żeby zrobić herbatę dla 5 osób, a nie jednej?"

**Co chcesz usłyszeć:** "zrób herbatę" to nazwa procedury. "Dla ilu osób?" to parametr — różnicuje wykonanie. Mama nie musi tłumaczyć kroków za każdym razem.

## Krok 2 — Mostek (5 min)
**Mostek:** "To samo robi **funkcja** w programowaniu. Raz definiujesz 'jak coś zrobić', potem wywołujesz wiele razy z różnymi danymi. To skraca kod i czyni go czytelnym."

**Minimalny przykład:**
```python
def przywitaj(imie):
    print(f"Cześć, {imie}!")

przywitaj("Anna")
przywitaj("Borys")
```

**Pytania:**
- "Gdzie tu jest 'definicja' a gdzie 'wywołanie'?"
- "Co robi `imie` w pierwszej linii? Skąd Python wie, że to ma być 'Anna'?"

Wprowadź pojęcia: **funkcja**, **definicja** (`def`), **parametr** (`imie` w definicji), **argument** (`"Anna"` przy wywołaniu), **wywołanie** (`przywitaj(...)`).

## Krok 3 — Eksperyment (15-20 min)
1. **Funkcja bez argumentów:**
```python
def powitanie():
    print("Cześć!")

powitanie()
powitanie()
```
2. **Funkcja z 1 argumentem:**
```python
def przywitaj(imie):
    print(f"Cześć, {imie}!")

przywitaj("Anna")
```
3. **Funkcja z `return`:**
```python
def dodaj(a, b):
    return a + b

wynik = dodaj(3, 5)
print(wynik)  # 8
```
4. **Funkcja zwraca, ale nikt nie przechwytuje:**
```python
dodaj(3, 5)   # nic się nie wyświetli — wartość "wyparowuje"
print(dodaj(3, 5))  # już tak — 8
```

**Co Python robi po `return`?** Wychodzi z funkcji. Pokaż:
```python
def test(x):
    if x > 0:
        return "dodatnia"
    return "niedodatnia"  # tu dojdzie tylko gdy x <= 0
    print("nie wyświetli się NIGDY")
```

## Krok 4 — Pogłębienie (15 min)

**`print` vs `return` — kluczowa różnica:**
```python
def kwadrat_print(x):
    print(x * x)

def kwadrat_return(x):
    return x * x

a = kwadrat_print(5)   # wypisuje 25, ale a == None
b = kwadrat_return(5)  # nic nie wypisuje, ale b == 25
print(a, b)            # None 25
```

**Pytanie do ucznia:** "Której funkcji użyłbyś, gdybyś chciał potem **policzyć sumę kwadratów**?"

**Funkcje bez `return` zwracają `None`:**
```python
def nic():
    pass  # 'nic nie rób'

x = nic()
print(x)  # None
```

**Funkcja może zwrócić wiele wartości (krotka!):**
```python
def min_max(lista):
    return min(lista), max(lista)

niski, wysoki = min_max([3, 7, 1, 9, 4])
print(niski, wysoki)  # 1 9
```
(To wzmianka — szczegóły argumentów nazwanych i domyślnych w lekcji 5.2.)

**Typowe błędy do sprowokowania:**
- Wywołanie bez nawiasów: `przywitaj "Anna"` → SyntaxError
- Brak `return` tam gdzie spodziewałeś wartości: `wynik = print("hej")` → wynik == None.
- **Mieszanie `print` i `return`** — najczęstszy błąd. Funkcja "drukująca" jest mniej elastyczna niż "zwracająca".

## Krok 5 — Ćwiczenie
→ Skill `cwiczenie`. Temat: "pierwsze funkcje". Sugerowane zadania:
- 🔥 Funkcja `kwadrat(x)` zwracająca `x*x`. Wywołaj dla 3, 5, 7.
- ⭐ Funkcja `powitaj(imie, godzina)` — wypisuje "Dzień dobry, [imię]" jeśli godzina < 18, inaczej "Dobry wieczór, [imię]".
- ⚡ Funkcja `srednia(lista)` zwracająca średnią arytmetyczną. Jak zachowa się dla pustej listy? (Pomyśl, potem sprawdź.) Zabezpiecz przed ZeroDivisionError.

## Pułapki
- **`print` to NIE `return`.** Funkcja drukująca nie pozwala "użyć" wyniku w dalszym kodzie.
- **Funkcja bez `return` zwraca `None`** — nie błąd, ale uczeń może być zaskoczony.
- **Wcięcie ciała funkcji** — musi być (standard: 4 spacje). Pomyłka w wcięciu = IndentationError.
- **Funkcję trzeba zdefiniować PRZED wywołaniem.** `def` musi być wyżej w pliku niż `przywitaj("Anna")`.
- **Nazwy funkcji** — `snake_case`, jak zmienne. `Przywitaj` (wielką literą) działa, ale to anty-idiom.

## Aktualizacja 2026 (z `AKTUALIZACJE.md`)
- **Type hints** (opcjonalne, ale zalecane w nowym kodzie):
```python
def kwadrat(x: int) -> int:
    return x * x
```
Wytłumacz: `x: int` mówi "spodziewam się int", `-> int` mówi "zwracam int". Python NIE sprawdza tego w runtime — to dokumentacja dla IDE i czytelnika.
- Wzmiankuj: w 3.12+ jest też `type Vector = list[float]` (PEP 695), ale dla początkującego — odłóż.

## Notatki tutora
- **Najważniejsze: `print` vs `return`.** Większość początkujących myli. Pokaż konsekwencje na przykładzie kwadratu.
- **Argumenty domyślne i nazwane** — to NASTĘPNA lekcja. Tu trzymaj się prostych pozycyjnych.
- Jeśli uczeń pyta o `*args` / `**kwargs` — odpowiedz "to zaawansowane, dojdziemy".
- **Funkcja = mała czarna skrzynka.** Wejście (argumenty) → wyjście (return). Promuj tę metaforę.
