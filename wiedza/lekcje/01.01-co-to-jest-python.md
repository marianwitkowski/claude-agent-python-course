# Lekcja 1.1 — Co to jest Python i do czego służy

## Cel
Po lekcji uczeń:
- Wymienia 3-4 konkretne zastosowania Pythona z życia
- Rozumie, że program = przepis dla komputera, a Python to język tego przepisu
- Potrafi uruchomić tryb interaktywny `python3` i wpisać pierwszy `print`

## Krok 1 — Zakotwiczenie (5 min)
**Pytanie wejściowe:**
> "Pomyśl o przepisie kulinarnym dla kogoś, kto nigdy nie gotował. Co taki przepis musi mieć, żeby zadziałał?"

**Co chcesz usłyszeć:** kolejność kroków, jednoznaczność, dokładne ilości, terminy (np. "zagotuj" musi być zdefiniowane). Słuchaj — niech uczeń sam dojdzie do "muszą być precyzyjne kroki".
**Czego NIE rób:** nie wprowadzaj jeszcze słów "program", "kod", "Python".

## Krok 2 — Mostek (5 min)
**Mostek:** "Program komputerowy to dokładnie taki przepis, tylko że dla komputera. A komputer jest bardzo dosłowny — każdy krok musi być jednoznaczny. Python to język, w którym piszemy te przepisy — celowo wygląda jak prawie-angielski, żeby człowiek mógł go czytać."

**Minimalny przykład:**
```python
print("Cześć!")
```

**Pytania:**
- "Spójrz na ten kod, nie znając Pythona. Domyślasz się, co robi?"
- "Co tu jest 'instrukcją', a co 'danymi do wykonania na nich'?"

## Krok 3 — Eksperyment (10-15 min)
Niech uczeń otworzy terminal i wpisze `python3` (sam, nie pokazuj mu zrzutu). Zobaczy `>>>`.

**Mini-zadania:**
1. Wpisz `print("dziala")` → Enter
2. Wpisz `2 + 2` → Enter (zwróć uwagę, że wynik się pokaże bez `print`)
3. Wpisz `"Anna" + " Kowalska"` → Enter (zaskakujące, że tekstów można "dodać")
4. Wpisz `exit()` → wyjście z trybu

**Po każdym pytaj:** "Co zobaczyłeś? Czego się spodziewałeś?"

Zadanie 3 — łączenie tekstów — to "smaczek". Niech uczeń sam zobaczy, że `+` w innym kontekście robi coś innego.

## Krok 4 — Pogłębienie (10 min)
> "Wymień mi 3 rzeczy, które znasz z życia, a które mogłyby być zrobione przez program w Pythonie."

Naprowadzaj na konkrety:
- Skrypt automatyzujący zadanie biurowe (np. zmiana nazw 1000 plików)
- Analiza danych z pliku Excel / CSV
- Prosta strona internetowa / API
- Gra tekstowa (kółko-krzyżyk w terminalu)
- Bot rozmawiający

Wspomnij krótko (1 zdanie każde):
- Python jest **interpretowany** (nie kompilowany jak C++) — można po prostu uruchomić, bez kompilacji
- Jest **dynamicznie typowany** — zmienna może raz trzymać liczbę, raz tekst (pokaż w `python3`: `x = 5`, potem `x = "kot"` — działa!)
- Ma **mnóstwo bibliotek** — `pip install <coś>` daje od razu narzędzia, których inaczej musiałbyś napisać samemu

## Krok 5 — Ćwiczenie
→ Skill `cwiczenie`. Temat: "pierwszy program". Sugerowane zadania:
- 🔥 Wypisz 3 print-y o sobie (imię, miasto, hobby)
- ⭐ Połącz tekst i liczbę w jednym print: `"Mam X lat"` gdzie X = twój wiek
- ⚡ Spróbuj `print(2 + "3")` — co się stanie? Dlaczego?

## Pułapki
- **`python` vs `python3`** — na macOS `python` może wskazywać na Python 2 (lub w ogóle nie istnieć). Zawsze `python3`.
- **Tryb interaktywny (`>>>`) vs plik (`python3 plik.py`)** — uczeń pomyli te dwa. W trybie interaktywnym nic się nie zapisuje.
- **`exit` bez nawiasów** — wyświetla pomoc; trzeba `exit()` (chociaż w 3.13+ samo `exit` też działa).

## Aktualizacja 2026 (z `AKTUALIZACJE.md`)
- **Python 3.13+ ma nowy REPL** z kolorowaniem składni i multi-line edit. Jeśli uczeń ma 3.13, strzałka w górę cofa cały blok, nie tylko linię. Powiedz wprost: to nowość, w starych tutorialach jest inaczej.
- **Lepsze tracebacki (3.11+)** — pokaż znaczek `^^^^^` pod miejscem błędu, jeśli wystąpi.
- **Tryb interaktywny dziś** jest dużo przyjemniejszy niż 5 lat temu — pokaż F3 (paste mode) jeśli uczeń ma 3.13.

## Notatki tutora
- **Nie wprowadzaj typów (`int`, `str`, `bool`)** — zostaw na lekcję 2.1. Mów po prostu "liczba", "tekst".
- Jeśli uczeń pyta "ale kiedy zaczniemy robić prawdziwe programy?" — przyznaj, że TO już są prawdziwe programy, tylko krótkie. Każdy duży program to setki takich linijek.
- Historia Pythona: **maks 1 zdanie**. "Powstał w 1991, autor: Guido van Rossum, nazwa od Monty Python (nie od węża)." Tyle.
- Jeśli uczeń się ekscytuje "a czy zrobimy AI / aplikację mobilną?" — odpowiedz "tak, w przyszłości, ale fundament musi być". Nie obiecuj.
