# Lekcja 12.1 — PEP 8 i czystość kodu

## Cel
Po lekcji uczeń:
- Wie czym jest PEP 8 — przewodnik stylu Pythona
- Stosuje konwencje: snake_case, 4 spacje, max 88-100 znaków w linii
- Używa `ruff format` do automatycznego formatowania
- Używa `ruff check` do wykrywania anty-idiomów
- Rozumie różnicę: "kod, który działa" vs "kod, który ŁATWO czytać"

## Krok 1 — Zakotwiczenie (3 min)
**Pytanie wejściowe:**
> "Wracasz do tekstu, który napisałeś rok temu. Bez poprawek interpunkcyjnych, akapitów, formatowania. Łatwo?"

**Co chcesz usłyszeć:** nie — czyta się gorzej, nawet jeśli treść jest dobra. **Forma ma znaczenie**. Tak samo z kodem — czysty kod to nie luksus, to inwestycja w przyszłego siebie.

## Krok 2 — Mostek (5 min)
**Mostek:** "**PEP 8** to oficjalny przewodnik stylu Pythona — jak nazywać zmienne, gdzie wstawiać spacje, jak organizować importy. Nie jest **wymuszany przez język** (Python uruchomi 'brzydki' kod), ale to **wspólny standard** całej społeczności."

**Korzyści:**
- Cudzy kod wygląda jak twój → łatwiej czytasz
- Twój kod wygląda jak cudzy → łatwiej dla innych
- Narzędzia (`ruff`, IDE) wymuszają automatycznie

## Krok 3 — Eksperyment (15-20 min)

### Najważniejsze reguły PEP 8

**1. Nazewnictwo:**
```python
# Zmienne i funkcje: snake_case
liczba_kotow = 5
def policz_kolory(...): ...

# Klasy: CamelCase
class KontoBankowe: ...

# Stałe: UPPER_SNAKE
MAX_LIMIT = 100
PI = 3.14159

# Prywatne (konwencja): podkreślnik
_helper = ...
class K:
    def __init__(self):
        self._wewnetrzne = 5
```

**2. Wcięcia: 4 spacje (nie tabulatory!)**
```python
def f():
    if True:
        print("4 spacje")
```

**3. Długość linii: max ~88-100 znaków**
```python
# źle (jedna długa linia):
print("To jest bardzo długi tekst, który zawiera mnóstwo treści i zdecydowanie przekracza 100 znaków, co źle wygląda")

# dobrze (zawijanie):
print(
    "To jest bardzo długi tekst, który zawiera mnóstwo treści "
    "i mieści się w czytelnych liniach"
)
```

**4. Spacje wokół operatorów:**
```python
# źle:
x=5
y=x+1
print(x ,y)

# dobrze:
x = 5
y = x + 1
print(x, y)
```

**5. Pusta linia między funkcjami (2 puste), wewnątrz klasy (1 pusta):**
```python
def funkcja_jeden():
    return 1


def funkcja_dwa():
    return 2


class Klasa:
    def metoda_jeden(self):
        return 1

    def metoda_dwa(self):
        return 2
```

**6. Importy: trzy grupy, każda osobno**
```python
# Standardowa biblioteka:
import os
import json
from pathlib import Path

# Zewnętrzne:
import requests
import pytest

# Lokalne:
from src.main import dodaj
from src.io import wczytaj
```

**7. Docstringi:**
```python
def dodaj(a, b):
    """Sumuje dwie liczby.

    Args:
        a: Pierwsza liczba.
        b: Druga liczba.

    Returns:
        Suma a i b.
    """
    return a + b
```

**Eksperyment:** otwórz **brzydki** kod z poprzednich lekcji i przepisz wg PEP 8. Pokaż obie wersje.

### Automatyczne narzędzia — `ruff`

```bash
pip install ruff

# Sprawdzenie (zauważ błędy):
ruff check src/

# Automatyczna naprawa:
ruff check --fix src/

# Formatowanie (jak `black` + import sorting):
ruff format src/
```

Konfiguracja w `pyproject.toml`:
```toml
[tool.ruff]
line-length = 100
target-version = "py312"

[tool.ruff.lint]
select = ["E", "W", "F", "I", "B", "UP"]
```

## Krok 4 — Pogłębienie (10 min)

### Anty-idiomy do unikania

**1. `import *`:**
```python
# źle (zaśmieca przestrzeń nazw):
from math import *

# dobrze:
from math import sqrt, pi
# lub:
import math
```

**2. Mutowalne wartości domyślne** (powtórka z 5.2):
```python
# źle:
def f(x=[]):

# dobrze:
def f(x=None):
    if x is None:
        x = []
```

**3. `==` z `None`:**
```python
# źle:
if x == None:

# dobrze:
if x is None:
```

**4. Niejasne nazwy zmiennych:**
```python
# źle:
x = ucz()
for i in dane:
    t = i["t"]
    process(t)

# dobrze:
uczniowie = pobierz_uczniow()
for uczen in uczniowie:
    temat = uczen["temat"]
    przetworz(temat)
```

**5. Zbyt długie funkcje:**
- Funkcja > 30 linii → rozważ podział
- Funkcja > 50 linii → na pewno podziel

**6. Magic numbers:**
```python
# źle:
if temperatura > 36.6:

# dobrze:
NORMALNA_TEMP = 36.6
if temperatura > NORMALNA_TEMP:
```

### Zasada "Zen of Python" — `import this`

Wpisz w REPL:
```python
import this
```
Zobaczysz "The Zen of Python" — manifest filozofii języka:
> Beautiful is better than ugly.
> Explicit is better than implicit.
> Simple is better than complex.
> Readability counts.

Niech uczeń przeczyta — to fundament myślenia "po Pythonowemu".

## Pułapki
- **Mieszanie spacji z tabami** — `IndentationError: inconsistent use of tabs and spaces`.
- **Linia 200 znaków** — czytasz przewijając. Złe.
- **Zmienne `x`, `tmp`, `dane`** — bez kontekstu są bezsensowne.
- **Komentarze opisujące CO** zamiast DLACZEGO — `# zwiększ x o 1` jest bezużyteczne. `# kompensacja off-by-one` ma sens.
- **Dogmatyzm** — PEP 8 to **przewodnik**, nie ewangelia. Czasem łamiesz dla czytelności.
