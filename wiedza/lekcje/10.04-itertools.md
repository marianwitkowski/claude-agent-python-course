# Lekcja 10.4 — `itertools`: magiczne pętle

## Cel
Po lekcji uczeń:
- Używa `chain`, `zip`, `enumerate` — łączenie i iteracja parami
- Zna `groupby`, `accumulate`, `count` — zaawansowane wzorce
- Używa `combinations`, `permutations` — kombinatoryka
- Wie, że `itertools` to **leniwy** moduł — wydajny pamięciowo

## Krok 1 — Zakotwiczenie (3 min)
**Pytanie wejściowe:**
> "Masz 3 osoby i 3 zadania. Chcesz wszystkich sparować z każdym zadaniem (każdy robi każde). Ile par? Jak byś je wypisał?"

**Co chcesz usłyszeć:** 9 par (3×3). Wypiszę "ręcznie": Anna-A, Anna-B, Anna-C, Borys-A, .... Tu pomocna jest **kombinatoryka** — `itertools` ma to wbudowane.

## Krok 2 — Mostek (5 min)
**Mostek:** "`itertools` to moduł stdlib z funkcjami do **iteracji** — łączenie, dzielenie, grupowanie, kombinatoryka. Wszystkie zwracają iteratory (leniwe), więc działają nawet na 'nieskończonych' sekwencjach."

**Minimalny przykład:**
```python
from itertools import chain

a = [1, 2, 3]
b = [4, 5, 6]
c = list(chain(a, b))   # zamiast a + b
print(c)   # [1, 2, 3, 4, 5, 6]
```

## Krok 3 — Eksperyment (15-20 min)

**`zip` (wbudowane!) — iteracja parami:**
```python
imiona = ["Anna", "Borys", "Cecylia"]
wieki = [30, 25, 40]

for imie, wiek in zip(imiona, wieki):
    print(f"{imie} ma {wiek}")
```

**`chain` — łączenie iteratorów:**
```python
from itertools import chain

print(list(chain([1,2], [3,4], [5,6])))   # [1,2,3,4,5,6]

# Spłaszczenie listy list:
listy = [[1,2], [3,4], [5,6,7]]
plaska = list(chain.from_iterable(listy))
print(plaska)   # [1,2,3,4,5,6,7]
```

**`count` — nieskończony licznik (UWAGA na pętlę bez break!):**
```python
from itertools import count

for i in count(10, 2):    # od 10, krok 2
    print(i)
    if i > 20:
        break   # bez tego — nieskończona pętla!
```

**`cycle` — zapętlenie:**
```python
from itertools import cycle

c = cycle(["A", "B", "C"])
print([next(c) for _ in range(7)])   # ['A','B','C','A','B','C','A']
```

**`repeat`:**
```python
from itertools import repeat
print(list(repeat("ok", 4)))   # ['ok','ok','ok','ok']
```

**`accumulate` — sumy częściowe / akumulacja:**
```python
from itertools import accumulate

liczby = [1, 2, 3, 4, 5]
print(list(accumulate(liczby)))           # [1, 3, 6, 10, 15] — sumy częściowe
print(list(accumulate(liczby, lambda a,b: a*b)))   # [1, 2, 6, 24, 120] — iloczyny
```

**Po każdym pytaj:** "Co Python zrobił? Czemu iterator, a nie lista?"

## Krok 4 — Pogłębienie (10-15 min)

**`groupby` — grupowanie kolejnych:**
```python
from itertools import groupby

dane = "aaabbcdddee"
for klucz, grupa in groupby(dane):
    print(klucz, list(grupa))
# a ['a', 'a', 'a']
# b ['b', 'b']
# c ['c']
# d ['d', 'd', 'd']
# e ['e', 'e']
```
**UWAGA:** `groupby` grupuje **kolejne** identyczne — żeby zgrupować po wartości, najpierw sortuj!

```python
osoby = [
    {"imie": "Anna", "miasto": "Warszawa"},
    {"imie": "Borys", "miasto": "Kraków"},
    {"imie": "Cecylia", "miasto": "Warszawa"},
]
# Sortujemy po mieście, potem grupujemy:
osoby_sorted = sorted(osoby, key=lambda o: o["miasto"])
for miasto, grupa in groupby(osoby_sorted, key=lambda o: o["miasto"]):
    print(miasto, [o["imie"] for o in grupa])
# Kraków ['Borys']
# Warszawa ['Anna', 'Cecylia']
```

**`combinations` i `permutations`:**
```python
from itertools import combinations, permutations

# Kombinacje (bez kolejności):
print(list(combinations([1,2,3], 2)))
# [(1,2), (1,3), (2,3)]

# Permutacje (z kolejnością):
print(list(permutations([1,2,3], 2)))
# [(1,2), (1,3), (2,1), (2,3), (3,1), (3,2)]
```

**`product` — iloczyn kartezjański:**
```python
from itertools import product

osoby = ["Anna", "Borys"]
zadania = ["A", "B", "C"]
for o, z in product(osoby, zadania):
    print(f"{o} robi {z}")
# 6 par
```

**`takewhile` i `dropwhile`:**
```python
from itertools import takewhile, dropwhile

liczby = [1, 3, 5, 7, 4, 8, 9]
print(list(takewhile(lambda x: x < 6, liczby)))   # [1,3,5] — bierz dopóki <6
print(list(dropwhile(lambda x: x < 6, liczby)))   # [7,4,8,9] — pomiń dopóki <6
```

**Typowe błędy do sprowokowania:**
- `count()` bez `break` → nieskończona pętla.
- `groupby` bez sortowania → tylko kolejne identyczne grupowane.
- Zapomnienie `list(...)` przy demonstracji.

## Pułapki
- **`count`/`cycle` to nieskończone** — zawsze daj limit (`islice`, `break`).
- **`groupby` wymaga sortowania** — inaczej zgrupuje tylko kolejne.
- **Iteratory są jednorazowe** — `list(...)` raz, potem iterator wyczerpany.
- **`zip` przycina do najkrótszej listy** — `list(zip([1,2,3], [10,20]))` to `[(1,10),(2,20)]`, nie błąd.
- **`zip(strict=True)`** (3.10+) — rzuca błąd jeśli długości różne.
