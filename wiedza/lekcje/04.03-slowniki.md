# Lekcja 4.3 — Słowniki: klucz/wartość, iteracja

## Cel
Po lekcji uczeń:
- Tworzy słownik `{klucz: wartość}`
- Dodaje, modyfikuje, usuwa wpisy
- Iteruje po kluczach, wartościach, parach
- Wie, że słownik jest **uporządkowany** od Python 3.7

## Krok 1 — Zakotwiczenie (5 min)
**Pytanie wejściowe:**
> "Pomyśl o książce telefonicznej. Po czym szukasz numeru — po numerze czy po nazwisku?"

**Co chcesz usłyszeć:** po nazwisku. Nazwisko to **klucz**, numer to **wartość**. To esencja słownika.

## Krok 2 — Mostek (5 min)
**Mostek:** "Słownik (`dict`) to **kolekcja par klucz-wartość**. Nie szukamy po pozycji (jak w liście), tylko po kluczu — jak w prawdziwym słowniku."

**Minimalny przykład:**
```python
osoba = {"imie": "Anna", "wiek": 30, "miasto": "Warszawa"}
print(osoba["imie"])  # Anna
```

**Pytania:**
- "Co tu jest kluczem? Co wartością?"
- "Czemu nawiasy `{}` zamiast `[]`?" (odróżnia od listy)
- "Czemu klucze są w cudzysłowach?" (bo to stringi; klucze mogą być różnych typów, ale najczęściej stringi)

## Krok 3 — Eksperyment (15-20 min)
1. **Dostęp do wartości:** `osoba["wiek"]` → 30
2. **Dodanie nowej pary:** `osoba["zawod"] = "programistka"`
3. **Modyfikacja:** `osoba["wiek"] = 31` (klucz ten sam, nowa wartość)
4. **Sprawdzenie czy klucz istnieje:** `"imie" in osoba` → True
5. **Bezpieczny dostęp:** `osoba.get("zawod")` → "programistka"; `osoba.get("haslo")` → None (zamiast błędu); `osoba.get("haslo", "brak")` → "brak"
6. **Usuwanie:** `del osoba["miasto"]` lub `osoba.pop("miasto")`
7. **Długość:** `len(osoba)` → liczba par

**Iteracja — 3 sposoby:**
```python
# po kluczach (domyślnie):
for klucz in osoba:
    print(klucz, "->", osoba[klucz])

# po wartościach:
for wartosc in osoba.values():
    print(wartosc)

# po parach (najczęstsze!):
for klucz, wartosc in osoba.items():
    print(f"{klucz}: {wartosc}")
```

**Po każdym pytaj:** "Co Python wypisał? Jaką informację dostałeś?"

## Krok 4 — Pogłębienie (15 min)

**Klucze mogą być różnych typów:**
- string — najczęściej
- int — `{1: "jeden", 2: "dwa"}`
- krotka — `{(0, 0): "start", (10, 10): "meta"}`
- **NIE lista!** Lista jest mutowalna → nie może być kluczem. Niech uczeń sprawdzi:
```python
{[1,2]: "test"}  # TypeError: unhashable type: 'list'
```

**Słownik w słowniku (zagnieżdżenia):**
```python
uczniowie = {
    "Anna": {"wiek": 14, "ocena": 5},
    "Borys": {"wiek": 15, "ocena": 4},
}
print(uczniowie["Anna"]["ocena"])  # 5
```

**Praktyczny przykład — liczenie wystąpień:**
```python
tekst = "ala ma kota a kot ma ale"
slowa = tekst.split()
licznik = {}
for slowo in slowa:
    if slowo in licznik:
        licznik[slowo] += 1
    else:
        licznik[slowo] = 1
print(licznik)
```
Niech uczeń przewidzi wynik, zanim uruchomi.

**Typowe błędy do sprowokowania:**
- `osoba["xyz"]` — klucz nie istnieje → `KeyError`. Używaj `.get()`.
- `osoba = {1: "a", 1: "b"}` — duplikat klucza, ostatni wygrywa. Sprawdź.
- Próba użycia listy jako klucza → TypeError.

## Krok 5 — Ćwiczenie
→ Skill `cwiczenie`. Temat: "słownik w praktyce". Sugerowane zadania:
- 🔥 Stwórz słownik z 3 swoimi danymi (imię, wiek, miasto). Wypisz wszystkie pary.
- ⭐ "Książka telefoniczna" — słownik kontaktów. Pytaj o nazwisko, wypisz numer (lub "brak").
- ⚡ "Częstość liter" — wczytaj zdanie, policz ile razy każda litera występuje. Zwróć słownik. (Inspiracja: licznik wyżej, tylko po literach zamiast słowach.)

## Pułapki
- **`KeyError`** — dostęp do nieistniejącego klucza. Używaj `.get()`.
- **`d = {}` to pusty słownik**, NIE pusty zbiór (set). Pusty set: `set()`.
- **Klucze muszą być niemutowalne** — string, int, krotka. Lista nie.
- **Klucze są unikalne** — drugi przypisanie nadpisuje.
- **Iteracja po słowniku iteruje po kluczach** (domyślnie). Pamiętaj o `.items()` gdy chcesz pary.

## Aktualizacja 2026 (z `AKTUALIZACJE.md`)
- **Słowniki są uporządkowane** od Python 3.7 (gwarancja języka). W starych tutorialach piszą "nieuporządkowane" — to **nieprawda** w nowym Pythonie. Iteracja zachowuje kolejność wstawiania.
- **`dict[str, int]` jako type hint** (3.9+): `def f(d: dict[str, int]):`. Nie wymuszaj.
- **Dict comprehensions** — wspomnij jako "kiedyś dojdziemy" (moduł 10): `{k: v*2 for k, v in d.items()}`.

## Notatki tutora
- **Słownik to NAJWAŻNIEJSZA struktura** w Pythonie — używana wszędzie (JSON-y, konfiguracje, dane). Poświęć tu czas.
- **`.items()` to TWÓJ przyjaciel** — uczeń będzie go używał w 80% iteracji po słownikach.
- **Nie wprowadzaj `defaultdict` ani `Counter`** — to moduł 9 (stdlib).
- Pokaż, jak słowniki **modelują dane** — "osoba" to słownik z polami. Pomost do OOP (moduł 7).
