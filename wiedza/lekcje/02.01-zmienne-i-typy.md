# Lekcja 2.1 — Zmienne i typy proste

## Cel
Po lekcji uczeń:
- Tworzy zmienną i zmienia jej wartość
- Rozróżnia 4 typy: `int`, `float`, `str`, `bool`
- Konwertuje typy świadomie (`int("5")`, `str(3.14)`)
- Używa `type(x)` do sprawdzania typu

## Krok 1 — Zakotwiczenie (5 min)
**Pytanie wejściowe:**
> "Pomyśl o pudełkach w spiżarni. Każde ma naklejkę: 'cukier', 'mąka', 'sól'. Co jest na naklejce, a co w środku? Czy można wymienić zawartość, zostawiając naklejkę?"

**Co chcesz usłyszeć:** naklejka = nazwa (etykieta), zawartość = wartość, można podmieniać zawartość pod tą samą naklejką.
**Czego NIE rób:** nie wypowiadaj słów "zmienna" ani "wartość".

## Krok 2 — Mostek (5 min)
**Mostek:** "To co opisałeś — pudełko z naklejką i zawartością — w Pythonie nazywamy **zmienną**. Naklejka to nazwa, zawartość to wartość."

**Minimalny przykład:**
```python
cukier = 5
print(cukier)
```

**Pytania:**
- "Co tu jest naklejką? Co zawartością?"
- "Czemu nie ma cudzysłowów wokół `cukier` przy `print`?"

Dopiero teraz wprowadź pojęcia: **zmienna**, **przypisanie** (znak `=`), **wartość**.

## Krok 3 — Eksperyment (15 min)
Uczeń w REPL lub pliku `zmienne.py`:

1. Stwórz zmienną `mleko = 2`. Wypisz ją.
2. Zmień `mleko = 3`. Wypisz ponownie. Co się stało ze starą wartością?
3. Spróbuj `mleko = "pełne"` (z cudzysłowem) — działa? (tak — Python jest dynamiczny)
4. `imie = "Anna"`. Wypisz `imie`. Co jest inne od `mleko = 3`?

**Wprowadź 4 typy** — eksperymentem:
5. `wiek = 30` → `type(wiek)` → `<class 'int'>` (liczba całkowita)
6. `wzrost = 1.75` → `type(wzrost)` → `<class 'float'>` (zmiennoprzecinkowa)
7. `imie = "Anna"` → `type(imie)` → `<class 'str'>` (string, tekst)
8. `czy_pelnoletni = True` → `type(czy_pelnoletni)` → `<class 'bool'>` (boolean, prawda/fałsz)

**Po każdym pytaj:** "Co Python ci pokazał? Domyślasz się, co to znaczy?"

## Krok 4 — Pogłębienie (15 min)
**Konwersje typów:**
- `int("5")` → 5 (str → int)
- `str(3.14)` → "3.14" (float → str)
- `float("2.5")` → 2.5
- `int(3.7)` → 3 (obcina, nie zaokrągla!)
- `bool(0)` → False, `bool(1)` → True, `bool("")` → False, `bool("ala")` → True

**Co zaskakujące:**
- `int("5.5")` → **błąd!** (`ValueError`). Najpierw `float`, potem `int`.
- `int(True)` → 1, `int(False)` → 0 (booleany to "ukryte" liczby)

**Typowe błędy do sprowokowania:**
- `"5" + 3` → `TypeError: can only concatenate str (not "int") to str`. Niech uczeń sam to wywoła.
- `wiek = 30` (bez cudzysłowów) vs `wiek = "30"` (z cudzysłowami) — różnica w działaniu.

**Reguły nazewnictwa zmiennych:**
- snake_case (małe litery, podkreślniki): `liczba_kotow`, nie `liczbaKotow`
- mogą zawierać litery, cyfry, `_`, ale **nie** zaczynają się od cyfry
- nie używaj słów kluczowych Pythona (`for`, `if`, `class` — Python nie pozwoli)

## Krok 5 — Ćwiczenie
→ Skill `cwiczenie`. Temat: "zmienne i typy". Sugerowane zadania:
- 🔥 Stwórz `imie`, `wiek`, `ulubiony_kolor`. Wypisz każdą.
- ⭐ Wizytówka: `imie`, `nazwisko`, `wiek`, `miasto` → wypisz w jednym zdaniu (jeszcze bez f-stringów, użyj przecinków w print)
- ⚡ Konwertuj: weź string `"42"`, zamień na int, dodaj 8, wypisz wynik

## Pułapki
- **`x = 5` vs `x == 5`** — pojedyncze `=` to przypisanie, podwójne `==` to porównanie (wprowadzimy w 3.1, ale uczeń może na to wpaść już teraz)
- **Polskie znaki w nazwach zmiennych** — DZIAŁAJĄ (`żółw = 2`), ale unikaj. Konwencja to angielski lub polski bez znaków.
- **Spacje w nazwach NIE działają** — `liczba kotow` to dwa słowa, błąd składni.
- **Nadpisanie wbudowanych nazw** — `list = [1,2,3]` to legalne, ale od teraz nie możesz użyć `list()` jako funkcji. Unikaj nazw: `list`, `dict`, `str`, `int`, `type`, `id`.

## Aktualizacja 2026 (z `AKTUALIZACJE.md`)
- **Type hints (opcjonalne)** — wspomnij na końcu lekcji: można pisać `wiek: int = 30` — Python to ignoruje w runtime, ale IDE i czytelnicy widzą intencję. Nie wymuszaj.
- **f-stringi 3.12+** — pełna swoboda cudzysłowów w środku (PEP 701), ale wprowadzimy w 2.3.
